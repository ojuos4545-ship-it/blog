주제: $ARGUMENTS

아래 순서대로 블로그 글을 작성해 주세요.

1. `docs/guides/style-guide.md`, `docs/guides/seo-guide.md`를 끝까지 읽습니다. 읽기 전에는 글을 쓰지 않습니다.
2. 주제에서 아래 세 가지를 정합니다.
   * 글 유형: A 정보·리뷰 / B 가이드 / C 에세이
   * 메인 키워드 1개 (롱테일)
   * 검색 의도 한 문장
3. 제목(25~35자, 키워드 앞쪽 1회)을 정하고, 해당 유형의 뼈대대로 본문을 씁니다.
4. 이미지가 들어갈 자리에 `[IMAGE: 종류 | 설명: ...]` 마커를 넣습니다. 썸네일 포함 5~10개입니다.
5. 글 끝에 태그 5~10개를 붙입니다.
6. `docs/drafts/<주제-슬러그>.md`로 저장합니다.
7. style-guide 8장, seo-guide 11장 체크리스트를 직접 확인합니다. 특히 한 줄 40자 이하, 본문 1,500자 이상, 키워드 3~5회를 셉니다.
8. 결과를 한글로, 결론 먼저 보고합니다.
   * 저장한 파일 경로
   * 선택한 유형, 메인 키워드, 제목
   * 체크리스트 통과 여부와 고친 부분
   * 사용자가 채워야 할 `[경험 입력: ...]` 자리

규칙:
* 직접 경험, 수치, 날짜를 지어내지 않습니다. 모르면 `[경험 입력: ...]`로 비워 둡니다.
* 이미지 파일은 만들지 않습니다. 마커만 넣습니다. 이미지 제작은 사용자가 따로 요청할 때 `docs/guides/image-guide.md`를 읽고 진행합니다.
* 주제가 비어 있으면 주제를 한 번만 물어봅니다.
