# 클로드 코드 모델 변경 방법 3단계 총정리

> 💡 **한 줄 요약:** 대화 중엔 `/model`, 실행할 땐 `--model`,
> 늘 쓸 기본값은 설정 파일로 바꾸면 됩니다.

[IMAGE: 썸네일 | 설명: 클로드 코드 모델 변경 방법 3단계 총정리 대표 이미지]

결론부터 말씀드리면, **클로드 코드 모델 변경**은
대화 중에는 `/model`, 실행할 때는 `--model`,
계속 쓸 기본값은 설정 파일의 `model` 값으로 정하면 됩니다.
"지금 오퍼스인지 소넷인지도 모르고 쓰고 있었어요"
하시는 분들을 위해 준비했습니다.

저도 처음엔 화면 어디에 모델이 나오는지 몰라서
한동안 기본값 그대로 썼어요.
지금 쓰는 모델을 어떻게 확인하고 바꾸는지 묻는 질문이
커뮤니티에 꽤 자주 올라오더라고요.

오늘 이 글 하나만 끝까지 읽으시면
상황에 맞는 방법을 골라 직접 바꾸실 수 있습니다.
명령어와 설정은 [Claude Code 공식 문서](https://code.claude.com/docs/en/model-config)를
2026년 11월 1일에 확인해 정리했습니다.

---

## 🛠️ 시작하기 전에 알아 둘 모델 별칭

* **준비물:** 클로드 코드 설치, 로그인된 계정
* **소요 시간:** 명령 한 줄이라 금방 끝납니다
* **난이도:** 초급, 명령어를 입력해 봤다면 충분합니다

모델은 긴 정식 이름 대신 짧은 별칭으로 부를 수 있습니다.
별칭은 그 계열의 권장 버전을 가리키고,
새 버전이 나오면 가리키는 모델도 함께 바뀌죠.
많은 분들이 궁금해하시는 부분이라 표로 정리했습니다.

| 별칭 | 이럴 때 씁니다 |
| :--- | :--- |
| `opus` | 복잡한 추론이 필요한 작업 |
| `sonnet` | 매일 하는 코딩 작업 |
| `haiku` | 간단하고 빠르게 끝낼 작업 |
| `opusplan` | 계획은 opus, 실행은 sonnet |
| `default` | 지정을 지우고 계정 기본값으로 |

[IMAGE: 비교표 | 설명: 클로드 코드 모델 별칭 opus, sonnet, haiku, opusplan, default 용도 비교]

Anthropic API 기준으로 `opus`는 Opus 5.5,
`sonnet`은 Sonnet 5.5, `haiku`는 Haiku 5.5를 가리킵니다.
구독 요금제와 API의 기본 모델은 Opus 5.5이고,
특정 버전에 고정하려면 `claude-opus-5-5`처럼
정식 이름을 그대로 쓰면 됩니다.

## Step 1. /model로 대화 중에 바꾸려면?

클로드 코드 모델 변경을 처음 할 때 가장 헷갈리는 부분은
바꾼 모델이 어디까지 적용되느냐입니다.
아래 순서대로 차근차근 따라와 주세요.

1. 클로드 코드 대화창에 `/model`을 입력합니다.
2. 목록에서 원하는 모델로 이동합니다.
3. `Enter`를 누르면 바로 바뀌고 기본값으로 저장됩니다.

이번 세션에만 쓰려면 `Enter` 대신 `s`를 누르면 됩니다.
목록을 열지 않고 바로 바꾸려면 별칭을 붙여 입력합니다.

```
/model sonnet
```

바꾼 뒤에는 `/status`로 지금 쓰는 모델을 확인할 수 있습니다.
상태 표시줄을 설정해 두셨다면 화면에서도 바로 보이죠.

[IMAGE: 포인트카드 | 설명: 클로드 코드 /model 명령으로 대화 중 모델을 바꾸는 순서]

저도 한 창에서 모델을 바꿨더니 다른 터미널 창의 모델까지
같이 바뀐 것 같아 당황한 적이 있어요.
비슷한 보고가 깃허브 이슈에 여러 번 올라왔더라고요.
`/model`이 고른 값을 사용자 설정에 기본값으로 저장하기 때문이라,
창마다 다르게 쓰고 싶다면 Step 2 방법이 편합니다.

> 📌 **전문가 Tip:** 모델과 함께 생각의 깊이도 조절할 수 있습니다.
> `/effort`를 입력하면 low부터 max까지 노력 수준을 고를 수 있어요.

---

## Step 2. 실행할 때 --model로 정하려면?

기본이 끝났다면 이제 실행할 때부터 모델을 정해 볼 차례입니다.
터미널에서 클로드 코드를 켤 때 옵션 하나만 붙이면 됩니다.

```bash
claude --model opus
```

`--model`로 정한 모델은 그렇게 실행한 세션에만 적용됩니다.
그래서 창마다 다른 모델을 쓰거나,
설정을 건드리지 않고 잠깐 시험해 볼 때 알맞죠.

환경 변수 `ANTHROPIC_MODEL`도 같은 역할을 합니다.
아래는 맥·리눅스 터미널 기준 예시입니다.

```bash
ANTHROPIC_MODEL=sonnet claude
```

환경 변수는 클로드 코드가 시작할 때 한 번 읽습니다.
이미 실행 중이라면 값을 바꾼 뒤 다시 시작해야 적용돼요.

[IMAGE: 포인트카드 | 설명: 클로드 코드 --model 옵션과 ANTHROPIC_MODEL 환경 변수로 실행할 때 모델 지정]

오퍼스로 오래 작업하다 사용량 한도에 빨리 닿아서
가벼운 작업은 소넷으로 내려 쓰는 분이 많더라고요.
저도 문서 정리나 간단한 수정은
`--model sonnet`으로 창을 따로 열어 처리하는 편이에요.

## Step 3. 설정 파일로 기본 모델을 고정하려면?

매번 고르기 번거롭다면 설정 파일에 기본 모델을 적어 둡니다.
사용자 설정 파일은 `~/.claude/settings.json`이고,
아래처럼 `model` 값 한 줄만 넣으면 됩니다.

```json
{
  "model": "opus"
}
```

프로젝트마다 다르게 쓰려면 프로젝트 폴더의
`.claude/settings.json`에 같은 값을 넣습니다.
그렇다면 여러 방법을 같이 쓰면 어느 쪽이 이길까요?
공식 문서에 나온 우선순위는 아래와 같습니다.

1. `/model` (대화 중에 바꾼 값)
2. `--model` (실행할 때 붙인 옵션)
3. `ANTHROPIC_MODEL` (환경 변수)
4. 설정 파일의 `model` 값

[IMAGE: 다이어그램 | 설명: 클로드 코드 모델 설정 우선순위 /model, --model, 설정 파일 흐름]

다만 프로젝트 설정과 관리자 설정은 예외입니다.
`/model`로 고른 값보다 앞서서 다음 실행 때 다시 적용되거든요.
모델이 자꾸 원래대로 돌아간다면 프로젝트 폴더의
설정 파일에 `model` 값이 있는지부터 확인해 보세요.

하지만 중요한 건 가장 좋은 모델을 고르는 것이 아니라
**작업에 맞는 모델**을 고르는 것이겠죠.
지정한 값을 모두 지우고 계정 기본값으로 돌아가고 싶다면
`/model default`를 입력하면 됩니다.

## 4. 마무리

오늘은 클로드 코드 모델 변경 방법을
`/model`, `--model`, 설정 파일의 3단계로 알아보았습니다.
지금 대화만 바꿀지, 이번 실행만 바꿀지,
앞으로 계속 쓸지만 정하면 방법은 저절로 골라집니다.

처음에는 `/model`로 한 번 바꿔 보고 `/status`로 확인해 보세요.
작은 설정 하나가 작업 흐름을 훨씬 가볍게 만들어 주는 법이죠!
