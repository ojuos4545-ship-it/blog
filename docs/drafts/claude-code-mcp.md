# 클로드 코드 MCP 사용법 3단계

> 💡 **한 줄 요약:** 클로드 코드 MCP는 명령 한 줄로 외부 도구를 연결하고, `/mcp`로 확인한 뒤, 공유 범위만 정하면 바로 쓸 수 있습니다.

[IMAGE: 썸네일 | 설명: 클로드 코드 MCP 사용법 3단계 대표 이미지]

"노션 내용을 복사해서 붙여넣는 것도 이제 지쳤어요" 하시는 분들을 위해 준비했습니다. 결론부터 말씀드리면, **클로드 코드 MCP**는 `claude mcp add` 명령 한 줄로 외부 도구를 연결하는 기능입니다. 연결만 해두면 클로드가 노션이나 데이터베이스 같은 도구를 직접 읽고 다룰 수 있죠.

오늘 이 글 하나만 끝까지 읽으시면 서버 연결, 상태 확인, 공유 범위 설정까지 혼자서 하실 수 있습니다. 지난 글들에서 CLAUDE.md, 스킬, 서브에이전트, 훅을 다뤘는데요. 핵심 기능 5가지 중 마지막 남은 MCP를 이번에 정리해 드리겠습니다.

---

## 1. MCP란 무엇이고 왜 필요할까?

MCP는 AI가 외부 도구와 주고받는 방식을 정해 둔 공개 표준입니다. 클로드 코드에 MCP 서버를 연결하면, 클로드는 그 도구의 기능을 자기 도구처럼 꺼내 씁니다. 채팅창에 자료를 붙여넣지 않아도 클로드가 직접 찾아 읽는 셈이죠.

공식 문서가 드는 예시는 이슈 트래커에서 일감을 가져와 구현하기, 데이터베이스 조회하기, 메일 초안 만들기 같은 일들입니다. 제가 직접 써보니 가장 크게 달라진 점은 "복사해서 붙여넣기" 과정이 사라졌다는 것이었습니다. 그렇다면 연결은 어떤 방식으로 이뤄질까요?

* **원격(HTTP) 서버:** 인터넷 주소로 연결합니다. 공식 문서가 권장하는 방식입니다.
* **로컬(stdio) 서버:** 내 컴퓨터에서 서버 프로그램을 직접 실행해 연결합니다.

[IMAGE: 다이어그램 | 설명: 클로드 코드가 MCP 서버를 거쳐 노션·데이터베이스 같은 외부 도구에 연결되는 흐름]

이 글의 명령어와 설정은 [Claude Code 공식 문서(MCP)](https://code.claude.com/docs/en/mcp)를 기준으로 정리했습니다.

---

## 🛠️ 시작하기 전에 준비할 것들

* **준비물:** 클로드 코드 설치, 연결할 도구의 계정(예: 노션)
* **소요 시간:** 약 10분
* **난이도:** 초급 (터미널에 명령어 한 줄 입력)

로컬 서버를 쓰려면 그 서버가 요구하는 실행 환경(예: Node.js)이 추가로 필요할 수 있습니다. 처음이라면 따로 설치할 게 없는 원격 서버부터 시작하시길 권해 드려요.

---

## Step 1. 클로드 코드 MCP 서버 연결하기

처음 시작할 때 가장 많이 실수하는 부분은 바로 명령어 순서입니다. 이름과 주소 자리가 바뀌면 연결이 되지 않으니, 아래 순서대로 차근차근 따라와 주세요.

1. 터미널에서 작업할 프로젝트 폴더로 이동합니다.
2. 아래 형식으로 원격 서버를 추가합니다. (이름은 내가 부를 별명, 주소는 서버 제공처가 알려준 URL입니다)
3. `claude mcp list`로 목록에 들어갔는지 확인합니다.

```bash
claude mcp add --transport http <이름> <주소>
```

노션을 예로 들면 다음과 같습니다.

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

로컬 서버는 `--` 뒤에 실행할 명령을 붙입니다. 이때 주의할 점은 `--` 앞은 클로드 코드 옵션, 뒤는 서버 실행 명령이라는 것입니다.

```bash
claude mcp add <이름> -- <실행 명령> [인자...]
```

[IMAGE: 포인트카드 | 설명: 클로드 코드 MCP 서버 관리 명령어 add, list, remove 정리]

> 📌 **전문가 Tip:** 연결한 서버를 지울 때는 `claude mcp remove <이름>`을 씁니다. 로그인했던 원격 서버라면 `claude mcp logout <이름>`을 먼저 실행해야 서비스 쪽 권한까지 정리됩니다.

---

## Step 2. `/mcp`로 상태 확인하고 로그인하기

기본이 끝났다면 이제 실제로 연결됐는지 확인해 볼 차례입니다. 클로드 코드를 실행한 뒤 대화창에 `/mcp`를 입력하면 서버 목록과 연결 상태가 나옵니다.

노션처럼 로그인이 필요한 서버는 이 메뉴에서 인증을 진행합니다. 브라우저 창이 열리면 평소처럼 로그인하고 접근을 허용하면 끝이죠. 로그인 정보는 안전하게 저장되고 자동으로 갱신되니 매번 다시 하실 필요는 없습니다.

[IMAGE: 포인트카드 | 설명: /mcp 메뉴에서 클로드 코드 MCP 연결 상태 확인과 로그인 순서]

연결이 확인되면 평소처럼 말로 부탁하면 됩니다.

```
노션에서 '주간 회의록' 페이지를 찾아서 이번 주 결정 사항만 정리해줘
```

> 📌 **전문가 Tip:** 서버 옆에 연결 실패 표시가 뜬다면 주소 오타부터 확인해 보세요. 헤더에 직접 넣은 인증 값이 거절되면 로그인 화면으로 넘어가지 않고 연결 실패로만 표시됩니다.

---

## Step 3. MCP 공유 범위는 어떻게 정할까?

MCP 서버는 어디에 저장하느냐에 따라 적용 범위가 달라집니다. 많은 분들이 궁금해하시는 부분이라 표로 정리했습니다.

| 범위 | 적용되는 곳 | 팀 공유 | 저장 위치 |
| :--- | :--- | :--- | :--- |
| **local** (기본값) | 현재 프로젝트 | 안 됨 | `~/.claude.json` |
| **project** | 현재 프로젝트 | 됨 (Git으로 공유) | 프로젝트 폴더의 `.mcp.json` |
| **user** | 내 모든 프로젝트 | 안 됨 | `~/.claude.json` |

범위는 `--scope` 옵션으로 정합니다. 팀원과 같은 서버를 쓰고 싶다면 아래처럼 `project`로 추가하면 되죠.

```bash
claude mcp add --transport http notion --scope project https://mcp.notion.com/mcp
```

[IMAGE: 비교표 | 설명: 클로드 코드 MCP 범위 local, project, user 장단점 비교]

| 범위 | 장점 👍 | 단점 👎 |
| :--- | :--- | :--- |
| **local** | 다른 프로젝트에 영향 없음 | 팀원은 각자 설정해야 함 |
| **project** | 팀 전체가 같은 도구 사용 | 처음 쓸 때 승인 과정 필요 |
| **user** | 한 번 설정으로 어디서나 사용 | 필요 없는 프로젝트에도 불러옴 |

하지만 중요한 건 서버를 많이 연결하는 게 아니라 **믿을 수 있는 서버만 연결하는 것**이겠죠. 공식 문서도 외부 내용을 가져오는 서버는 숨겨진 지시문으로 AI를 속이는 공격(프롬프트 인젝션)에 노출될 수 있다고 경고합니다. 출처가 분명한 공식 서버부터 쓰시는 게 안전합니다.

결과 길이도 함께 신경 써야 합니다. 클로드 코드는 MCP 도구 결과가 1만 토큰을 넘으면 경고를 띄우고, 기본 한도는 2만 5천 토큰입니다. 결과가 길수록 대화 공간을 많이 차지하니, 필요한 부분만 요청하는 습관이 도움이 됩니다.

## 자주 묻는 질문

**Q. 서버를 여러 개 연결해도 되나요?**
네, 여러 개 연결할 수 있습니다. 다만 같은 이름의 서버가 여러 범위에 있으면 local, project, user 순서로 하나만 쓰이고 설정이 합쳐지지는 않습니다.

**Q. 자동 실행(`claude -p`)에서도 로그인할 수 있나요?**
아니요, 비대화형 실행에서는 로그인을 끝낼 수 없습니다. 대화형 세션에서 `/mcp`로 먼저 로그인해 두셔야 합니다.

## 4. 마무리

오늘은 클로드 코드 MCP를 연결하고, 확인하고, 범위를 정하는 3단계를 알아보았습니다. 명령 한 줄과 `/mcp` 메뉴만 기억하시면 나머지는 금방 손에 익으실 거예요.

처음엔 서버 하나만 연결해도 충분합니다. 작은 연결 하나가 매일 반복하던 복사와 붙여넣기를 없애 주는 법이죠! 여러분의 작업 흐름을 가볍게 만드는 데 도움이 되었기를 바랍니다.
