# 챗GPT 엑셀 프롬프트 예시 7가지 총정리

> 💡 **한 줄 요약:** 엑셀 질문은 열 구성, 엑셀 버전,
> 원하는 결과를 함께 적어야 바로 쓰는 수식이 나옵니다.

[IMAGE: 썸네일 | 설명: 챗GPT 엑셀 프롬프트 예시 7가지 총정리 대표 이미지]

안녕하세요, 여러분! 결론부터 말씀드리면,
**챗GPT 엑셀 프롬프트**는 표의 열 구성과 엑셀 버전,
원하는 결과를 한 번에 알려 줄 때 가장 정확합니다.
함수 이름을 몰라도 상황만 설명하면 수식을 받을 수 있어요.

엑셀 함수는 외울 게 너무 많아서
검색창과 엑셀 화면을 오가며 한참 헤매셨죠?
저도 처음엔 "매출 합계 수식 알려줘"처럼 한 줄만 적었다가
제 표와 열 위치가 맞지 않는 수식을 받아 다시 물어야 했어요.

오늘은 수식 만들기와 오류 고치기부터 데이터 정리,
피벗 테이블, 매크로까지 바로 복사해 쓰는 예시 7가지를 정리해 드리겠습니다.
대괄호 안만 내 표에 맞게 바꾸면 되니
엑셀이 낯선 분들도 금방 따라 하실 수 있습니다.

## 1. 챗GPT 엑셀 프롬프트, 무엇을 알려 줘야 할까?

챗GPT는 내 엑셀 파일을 볼 수 없습니다.
파일을 올리지 않는 한 표가 어떻게 생겼는지 모르니,
아래 네 가지를 글로 설명해 주는 것이 출발점이죠.

* **열 구성:** 열마다 어떤 값이 있는지, 머리글이 몇 행인지
* **엑셀 버전:** Microsoft 365, 2021, 2016처럼 쓰는 버전
* **원하는 결과:** 어느 칸에 무엇이 나와야 하는지
* **조건과 예외:** 빈칸, 중복, 0 같은 특수한 경우

[IMAGE: 포인트카드 | 설명: 챗GPT 엑셀 프롬프트에 꼭 넣을 정보 4가지: 열 구성, 버전, 결과, 예외]

네 가지 중에서 가장 자주 빠지는 것은 열 구성입니다.
"A열은 날짜, B열은 담당자"처럼 적어 주면
내 표에 그대로 붙여 넣을 수 있는 수식이 나옵니다.

버전도 꼭 적어 주세요.
최신 함수는 오래된 엑셀에서 작동하지 않아서
버전을 모르면 내 컴퓨터에서 안 되는 수식을 받을 수 있거든요.

> 📌 **전문가 Tip:** 표 모양을 보여 주고 싶다면
> 실제 데이터 대신 가짜 값으로 서너 줄만 만들어 붙여 넣으세요.
> 구조는 그대로 전하면서 회사 정보는 지킬 수 있습니다.

## 2. 수식을 만들고 고치는 프롬프트 예시 3가지

엑셀에서 가장 많이 막히는 일은 역시 수식입니다.
합계, 값 찾기, 오류 고치기 순서로 세 가지를 골랐습니다.

[IMAGE: 비교표 | 설명: 수식을 만들고 고치는 챗GPT 엑셀 프롬프트 예시 3가지와 꼭 넣을 정보]

### 예시 1. 조건별 합계 구하기

```
엑셀 Microsoft 365를 쓰고 있어.
1행은 머리글이고, A열은 날짜, B열은 지점,
C열은 매출 금액이야.
F2칸에 [강남점]의 [10월] 매출 합계를 구하는
수식을 알려줘.
수식이 어떻게 동작하는지 한 줄씩 설명해줘.
```

열 구성과 결과가 나올 칸을 먼저 알려 준 것이 핵심입니다.
설명까지 받아 두면 다음에 비슷한 수식을 직접 고칠 수 있죠.

### 예시 2. 다른 표에서 값 찾아오기

```
엑셀 2016을 쓰고 있어.
'주문' 시트 A열에 상품 코드가 있고,
'상품목록' 시트 A열은 상품 코드, C열은 단가야.
'주문' 시트 D열에 코드에 맞는 단가를 불러오는
수식을 알려줘.
코드가 없으면 '확인 필요'라고 나오게 해줘.
```

값을 찾아오는 XLOOKUP 함수는 편리하지만,
Excel 2021이나 Microsoft 365부터 쓸 수 있는 함수입니다.
그래서 버전을 적어 주면 INDEX와 MATCH 조합처럼
내 엑셀에서 되는 방법으로 바꿔서 알려 줍니다.

### 예시 3. 오류 난 수식 고치기

```
엑셀 2019에서 아래 수식이 #NAME? 오류를 내.
원인을 찾고, 내 버전에서 되는 수식으로 고쳐줘.
고친 이유도 짧게 설명해줘.

[수식 붙여 넣기]
```

받은 수식을 회사 컴퓨터에 넣었더니
`#NAME?` 오류가 떴다는 분이 정말 많더라고요.
함수 이름 오타일 때도 있지만,
구버전 엑셀에 없는 최신 함수가 원인인 경우가 흔합니다.

오류를 물을 때는 수식을 다시 타이핑하지 말고
수식 입력줄에 있는 그대로 복사해 붙여 넣으세요.
`$` 표시 하나만 달라져도 원인이 달라지기 때문입니다.

## 3. 데이터 정리와 분석 프롬프트 예시 4가지

수식에 익숙해졌다면 이제 표 전체를 다루는 일을 맡겨 볼 차례입니다.
정리, 요약, 분석, 자동화 순서로 네 가지를 모았습니다.

[IMAGE: 비교표 | 설명: 데이터 정리와 분석에 쓰는 챗GPT 엑셀 프롬프트 예시 4가지]

### 예시 4. 지저분한 데이터 정리하기

```
B열에 고객 이름이 있는데 앞뒤에 공백이 섞여 있고,
C열 날짜는 '2026.10.3'처럼 점으로 적혀 있어.
공백을 지우고 날짜를 엑셀 날짜 형식으로 바꾸는
방법을 알려줘.
함수로 하는 방법과 메뉴로 하는 방법을 나눠서
순서대로 설명해줘.
```

데이터가 어떻게 지저분한지 예를 들어 적어 주는 것이 좋습니다.
방법을 두 가지로 받아 두면 내게 편한 쪽을 고를 수 있죠.

### 예시 5. 피벗 테이블 설계하기

```
A열 날짜, B열 지점, C열 상품, D열 매출이 있는
판매 기록이야.
지점별, 월별 매출 합계를 한눈에 보고 싶어.
피벗 테이블의 행, 열, 값에 무엇을 넣을지 알려주고
메뉴를 누르는 순서대로 설명해줘.
```

피벗 테이블은 어디에 무엇을 끌어다 놓을지가 가장 헷갈립니다.
행과 열, 값을 먼저 정해 달라고 하면
처음 써 보는 분도 순서대로 따라가기 쉬워요.

### 예시 6. 파일을 올려 분석과 차트 맡기기

```
첨부한 판매 기록 파일을 분석해줘.
월별 매출 흐름과 눈에 띄는 변화 3가지를 찾고,
월별 매출을 막대 차트로 그려줘.
계산에 쓴 기준과 빠진 데이터가 있었는지도 알려줘.
```

OpenAI 설명에 따르면 챗GPT는 올린 파일을 분석할 때
파이썬 코드를 직접 작성하고 실행해 결과를 냅니다.
여러 달의 표를 합쳐 피벗 형태로 정리하거나
차트를 그리는 일도 맡길 수 있습니다.

다만 결과는 대화창에 나오고 내 원본 파일은 바뀌지 않습니다.
고객 이름이나 연락처가 든 파일이라면
그 열을 지우거나 가명으로 바꾼 뒤 올리세요.

### 예시 7. 반복 작업 매크로 만들기

```
매일 아침 'Raw' 시트의 데이터를 'Report' 시트로
복사하고, D열 기준으로 내림차순 정렬하는 일을
반복하고 있어.
이 작업을 버튼 한 번으로 하는 VBA 매크로를 만들어줘.
코드마다 무엇을 하는지 주석을 달아줘.
```

매크로는 어떤 순서로 무엇을 하는지만 정확히 적으면 됩니다.
실행하기 전에는 꼭 원본 파일을 복사해 두고
사본에서 먼저 시험해 보세요.

## 4. 챗GPT로 만든 엑셀 수식, 어떻게 검증할까?

수식이 오류 없이 결과를 내도 그 값이 맞다는 보장은 없습니다.
엑셀은 문법만 맞으면 계산을 하니까요.
그래서 아래 세 단계로 확인하는 습관이 필요합니다.

1. 데이터 몇 줄로 된 작은 표에서 먼저 시험합니다.
2. 결과를 계산기나 손 계산과 맞춰 봅니다.
3. 맞으면 전체 범위에 적용하고 끝까지 훑어봅니다.

[IMAGE: 다이어그램 | 설명: 챗GPT 엑셀 프롬프트로 받은 수식을 검증하는 3단계: 작은 표 시험, 손 계산 대조, 전체 적용]

특히 수식을 아래로 끌어 채울 때 조심해야 합니다.
저도 첫 칸에서는 맞던 수식을 끌어 내렸더니
기준 칸이 함께 밀려 값이 엉뚱하게 나온 적이 있어요.

이럴 때는 고정해야 할 칸에 `$`를 붙여야 합니다.
처음부터 "끌어 채워도 기준 칸은 고정되게 해줘"라고
한 줄 덧붙이면 이런 실수를 줄일 수 있죠.

[IMAGE: 포인트카드 | 설명: 챗GPT 엑셀 활용 시 주의할 점 3가지: 개인정보 빼기, 작은 표로 시험, 원본 백업]

맡겨도 되는 일과 직접 확인할 일도 나눠 두면 편합니다.

| 맡기기 좋은 일 👍 | 직접 확인할 일 👎 |
| :--- | :--- |
| 수식 초안과 설명 | 계산 결과의 정확성 |
| 오류 원인 찾기 | 내 버전에서 작동 여부 |
| 정리 순서 안내 | 개인정보·기밀 포함 여부 |
| 매크로 초안 | 원본 백업과 시험 실행 |

보안도 꼭 챙겨야 합니다.
챗GPT에 입력한 내용은 외부 서버로 전송되기 때문에
고객 정보나 사내 기밀은 지우고 넣는 것이 원칙입니다.
회사에 AI 사용 규정이 있다면 그것부터 확인하시길 권합니다.
