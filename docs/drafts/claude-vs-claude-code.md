# 클로드와 클로드 코드 차이 4가지 정리

> 💡 **한 줄 요약:** 클로드는 묻고 답하는 AI 비서,
> 클로드 코드는 내 파일을 직접 고치는 코딩 에이전트입니다.

[IMAGE: 썸네일 | 설명: 클로드와 클로드 코드 차이 4가지 정리 대표 이미지]

안녕하세요, 여러분!
결론부터 말씀드리면, **클로드와 클로드 코드 차이**는
같은 AI가 대화만 하느냐, 내 파일을 직접 다루느냐에 있습니다.
클로드는 질문에 답을 주는 대화형 AI 비서이고,
클로드 코드는 프로젝트 폴더를 읽고 고치는 코딩 도구입니다.

이름이 비슷하다 보니 같은 서비스인지,
따로 가입해야 하는지 헷갈리셨죠?
저도 처음엔 채팅창에서 받은 코드를 편집기에 붙이고,
오류가 나면 다시 채팅창에 붙이는 일을 몇 번이고 반복했어요.

오늘은 정체, 일하는 방식, 쓰는 곳, 요금의
4가지 차이를 표와 함께 알기 쉽게 정리해 드리겠습니다.
내용은 [Claude Code 공식 문서](https://code.claude.com/docs/en/overview)와
[Claude 요금 페이지](https://claude.com/pricing)를
2026년 11월 1일에 확인해 담았어요.

## 1. 클로드와 클로드 코드 차이 - 한눈에 보면?

바쁘신 분들을 위해 4가지 차이를 먼저 표로 묶었습니다.
한 줄씩 읽어 보시면 두 도구의 성격이 금방 보이실 거예요.

| 구분 | 클로드 | 클로드 코드 |
| :--- | :--- | :--- |
| **정체** | 대화형 AI 비서 | 에이전트형 코딩 도구 |
| **일하는 방식** | 답을 주면 내가 옮김 | 파일을 직접 읽고 고침 |
| **쓰는 곳** | 웹, 데스크톱, 모바일 앱 | 터미널, IDE, 앱, 웹 |
| **요금** | 무료 플랜부터 | Pro 등 유료 플랜부터 |

[IMAGE: 비교표 | 설명: 클로드와 클로드 코드 차이 4가지 비교: 정체, 방식, 쓰는 곳, 요금]

두 도구는 모두 Anthropic이 만든 같은 Claude 모델을 씁니다.
그래서 똑똑함의 차이라기보다
**AI가 손댈 수 있는 범위**의 차이라고 보시면 쉬운데요.
클로드는 말로 돕고, 클로드 코드는 손까지 움직이는 셈이죠.

---

## 2. 클로드 코드는 클로드와 무엇이 다를까?

### 클로드는 묻고 답하는 AI 비서

클로드는 claude.ai 웹사이트와 앱에서 쓰는 대화형 AI입니다.
글쓰기, 요약, 번역, 아이디어 정리처럼
말로 주고받는 일을 폭넓게 도와주죠.

코드를 물어보면 답으로 코드를 보여 주지만,
기본적으로 내 컴퓨터의 프로젝트 폴더를 열어 보지는 못합니다.
그래서 받은 코드를 파일에 옮기고 실행하는 일은
사람이 직접 해야 합니다.

### 클로드 코드는 직접 손을 움직이는 에이전트

공식 문서는 클로드 코드를 코드베이스를 읽고,
파일을 고치고, 명령을 실행하는 에이전트형 코딩 도구라고 소개합니다.
"테스트를 짜고 돌려서 실패하면 고쳐줘"처럼 목표를 주면
계획을 세워 여러 파일을 고치고 결과까지 확인합니다.

git과도 바로 이어져서 변경 내용을 정리하고
커밋 메시지를 쓰거나 PR을 여는 일까지 맡길 수 있어요.
복사와 붙여넣기를 오가던 일이 줄어든다는 점이
가장 크게 느껴지는 차이입니다.

[IMAGE: 다이어그램 | 설명: 클로드 채팅과 클로드 코드의 일하는 흐름 차이]

> 📌 **전문가 Tip:** 클로드 코드는 프로젝트 폴더의
> `CLAUDE.md` 파일을 대화를 시작할 때마다 읽습니다.
> 코딩 규칙을 여기에 적어 두면 매번 설명할 필요가 없어요.

---

## 3. 어디서 쓰고, 요금은 어떻게 다를까?

### 쓰는 곳: 채팅창 vs 작업 공간

클로드는 웹, 데스크톱 앱, iOS와 안드로이드 앱의 채팅창에서 씁니다.
클로드 코드는 처음엔 터미널 도구로 알려졌지만,
지금은 쓰는 곳이 꽤 넓어졌습니다.

* **터미널:** 기능이 가장 많은 기본 형태
* **IDE:** VS Code 확장, JetBrains 플러그인
* **데스크톱 앱:** 클로드 앱 안의 Code 탭
* **웹:** claude.ai/code에서 설치 없이 실행

[IMAGE: 포인트카드 | 설명: 클로드 코드를 쓸 수 있는 곳: 터미널, IDE, 데스크톱 앱, 웹]

데스크톱 앱은 한 앱 안에 채팅과 Code 탭이 함께 있어서
여기서 많이들 헷갈리시죠.
채팅 탭은 일반 클로드이고,
**Code 탭을 눌러야** 클로드 코드로 작업할 수 있습니다.

### 요금: 무료 플랜에는 클로드 코드가 없다

요금 페이지 기준으로 무료 플랜에서도 클로드 채팅은 쓸 수 있지만,
클로드 코드는 포함되지 않습니다.
무료 계정으로 설치부터 했다가
쓸 수 없다는 걸 뒤늦게 알았다는 분이 꽤 많더라고요.

| 플랜 | 월 요금 (미국 기준) | 클로드 코드 |
| :--- | :--- | :--- |
| **Free** | 0달러 | 포함 안 됨 |
| **Pro** | 20달러 (연간 결제 시 월 17달러) | 포함 |
| **Max** | 100달러부터 | 포함, Pro보다 넉넉한 사용량 |
| **Team·Enterprise** | 좌석당 요금 | 포함 |

[IMAGE: 비교표 | 설명: 클로드 요금제별 클로드 코드 포함 여부 비교: Free, Pro, Max, Team]

구독 대신 Anthropic Console 계정의 API 사용료로
클로드 코드를 쓰는 방법도 있습니다.
다만 처음이라면 Pro 구독 하나로
채팅과 코딩을 함께 쓰는 쪽이 간단합니다.

하나 더 알아 둘 점은 **사용량 한도를 함께 쓴다**는 것인데요.
공식 도움말에 따르면 클로드와 클로드 코드의 사용량은
같은 한도에서 함께 빠져나갑니다.
저도 클로드 코드에 일을 길게 맡긴 날에는
채팅에서 쓸 여유가 확 줄어 있어서 당황한 적이 있어요.

## 4. 내 상황엔 무엇을 써야 할까?

많은 분들이 결국 궁금해하시는 부분입니다.
둘 중 하나만 골라야 하는 건 아니고,
하려는 일에 맞춰 나눠 쓰면 됩니다.

* **클로드가 맞는 일:** 글쓰기, 요약, 번역, 개념 질문
* **클로드 코드가 맞는 일:** 기능 추가, 버그 수정, 테스트
* **둘 다 쓰는 일:** 채팅으로 계획, 클로드 코드로 구현

[IMAGE: 포인트카드 | 설명: 상황별로 클로드와 클로드 코드 중 무엇을 쓸지 고르는 기준]

코딩을 하지 않는다면 클로드 채팅만으로도 충분합니다.
반대로 프로젝트 폴더가 있고 코드를 자주 고친다면
클로드 코드가 복사와 붙여넣기의 수고를 크게 덜어 주죠.

하지만 중요한 건 도구를 고르는 것보다
**맡길 일을 분명하게 말하는 것**이겠죠.
어느 쪽을 쓰든 목표와 조건을 구체적으로 적을수록
결과가 좋아집니다.
