# 클로드 코드 MCP 사용법 3단계 총정리

> 💡 **한 줄 요약:** 클로드 코드 MCP 사용법은 서버 연결, 상태 확인, 공유 범위 설정의 3단계로 끝납니다.

[IMAGE: 썸네일 | 설명: 클로드 코드 MCP 사용법 3단계 총정리 대표 이미지]

"외부 도구를 연결하라는데 명령어부터 막막해요" 하시는 분들을 위해 준비했습니다. 결론부터 말씀드리면, **클로드 코드 MCP 사용법**은 `claude mcp add` 명령으로 서버를 연결하고, `/mcp`로 상태를 확인한 뒤, 공유 범위만 정하면 됩니다.

MCP는 Model Context Protocol의 줄임말로, AI 도구가 외부 서비스와 연결되는 방식을 정해 둔 공개 표준입니다. 오늘 이 글 하나만 끝까지 읽으시면 서버 하나를 연결해서 직접 써 보는 데까지 혼자 하실 수 있습니다. 명령어와 설정은 2026년 10월 29일에 확인한 [Claude Code 공식 문서(MCP)](https://code.claude.com/docs/en/mcp)를 기준으로 정리했습니다.

---

## 🛠️ 시작하기 전에 준비할 것들

* **준비물:** 클로드 코드 설치, 연결할 서비스의 계정(예: 노션)
* **소요 시간:** [경험 입력: 서버 하나를 연결하는 데 실제로 걸린 시간]
* **난이도:** 초급 (터미널에 명령어를 입력해 본 적이 있으면 충분합니다)

처음이라면 원격(HTTP) 서버부터 시작해 보세요. 공식 문서도 원격 서버를 권장하고, 로컬 서버와 달리 내 컴퓨터에서 서버 프로그램을 따로 실행할 필요가 없어서 준비할 것이 적습니다.

---

## Step 1. 클로드 코드 MCP 서버는 어떻게 연결할까?

처음 연결할 때 헷갈리기 쉬운 부분은 바로 명령어 순서입니다. [경험 입력: 처음 연결할 때 막혔던 부분과 해결 방법] 아래 순서대로 차근차근 따라와 주세요.

1. 작업할 프로젝트 폴더로 이동합니다.
2. 연결 방식에 맞는 명령을 입력합니다. (원격 서버는 `--transport http`, 로컬 서버는 `--` 뒤에 실행 명령을 붙입니다)
3. `claude mcp list`로 목록에 들어갔는지 확인합니다.

원격 서버는 이름과 주소만 알면 됩니다. 노션을 예로 들면 아래와 같습니다.

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

로컬 서버는 `--`가 핵심입니다. `--` 앞은 클로드 코드의 옵션이고, 뒤는 서버를 실행하는 명령이라서 이 구분이 없으면 서버의 옵션을 클로드 코드가 자기 것으로 읽어 버립니다.

```bash
claude mcp add --transport stdio <이름> -- <실행 명령> [인자...]
```

[IMAGE: 포인트카드 | 설명: 클로드 코드 MCP 서버 관리 명령 add, list, get, remove 정리]

> 📌 **전문가 Tip:** 서버를 지울 때는 `claude mcp remove <이름>`을 씁니다. 원격 서버의 접근 권한까지 취소하고 싶다면, 먼저 `claude mcp logout <이름>`을 실행하세요. 이 명령은 인증 서버가 취소를 지원할 때만 서비스 쪽 토큰을 취소합니다.

---

## Step 2. /mcp로 연결 상태는 어떻게 확인할까?

기본이 끝났다면 이제 실제로 연결됐는지 확인해 볼 차례입니다. 클로드 코드를 실행하고 대화창에 `/mcp`를 입력하면 서버별 연결 상태가 나옵니다. 상태는 `Connected`, `Needs authentication`, `Failed to connect`처럼 표시됩니다.

노션처럼 로그인이 필요한 원격 서버는 같은 메뉴에서 인증을 진행합니다. 브라우저 창이 열리면 평소처럼 로그인하고 접근을 허용하면 되죠. 인증이 끝나면 평소처럼 말로 부탁해 보세요.

```
노션에서 '프로젝트 일정' 페이지를 찾아 마감이 가까운 항목만 알려줘
```

[IMAGE: 포인트카드 | 설명: /mcp 메뉴에서 클로드 코드 MCP 연결 상태를 확인하고 로그인하는 순서]

### 연결이 안 될 때는 어떻게 할까?

상태가 `Needs authentication`이면 `/mcp`에서 로그인을 진행하면 됩니다. `Failed to connect`라면 서버 이름과 주소에 오타가 없는지부터 확인해 보세요.

서버가 여러 개 끊겼다면 `/mcp reconnect all`로 한꺼번에 다시 연결할 수 있습니다. 이 명령은 클로드 코드 v2.1.284 이상에서 동작하니, 안 된다면 버전부터 확인해 보시기 바랍니다.

---

## Step 3. MCP 공유 범위는 어떻게 정할까?

MCP 서버는 어느 범위로 추가하느냐에 따라 쓰이는 곳이 달라집니다. 많은 분들이 궁금해하시는 부분이라 표로 정리했습니다.

| 범위 | 적용되는 곳 | 팀 공유 | 저장 위치 |
| :--- | :--- | :--- | :--- |
| **local** (기본값) | 현재 프로젝트만 | 안 됨 | `~/.claude.json` |
| **project** | 현재 프로젝트만 | 됨 (버전 관리) | 프로젝트 루트의 `.mcp.json` |
| **user** | 모든 프로젝트 | 안 됨 | `~/.claude.json` |

범위는 `--scope` 옵션으로 정합니다. 팀원과 같은 서버를 쓰고 싶다면 아래처럼 `project` 범위로 추가하면 됩니다.

```bash
claude mcp add --transport http --scope project notion https://mcp.notion.com/mcp
```

[IMAGE: 비교표 | 설명: 클로드 코드 MCP 범위 local, project, user의 장단점 비교]

| 범위 | 장점 👍 | 단점 👎 |
| :--- | :--- | :--- |
| **local** | 다른 프로젝트에 영향이 없음 | 팀원은 각자 설정해야 함 |
| **project** | 팀 전체가 같은 설정을 씀 | 처음 쓸 때 승인 절차가 있음 |
| **user** | 한 번 설정으로 모든 프로젝트에서 씀 | 필요 없는 프로젝트에도 연결됨 |

같은 이름의 서버가 여러 범위에 있으면 local, project, user 순서로 우선합니다. 프로젝트 범위 서버는 대화형 세션에서 처음 쓰기 전에 승인을 묻는데요. 이 선택을 초기화하려면 `claude mcp reset-project-choices`를 실행하면 됩니다.

하지만 중요한 건 서버를 많이 연결하는 것이 아니라 **믿을 수 있는 서버만** 연결하는 것이겠죠. 공식 문서도 외부 내용을 가져오는 서버는 프롬프트 인젝션(숨겨진 지시문으로 AI를 속이는 공격) 위험에 노출될 수 있다고 경고합니다.

결과 길이도 함께 살펴보세요. MCP 도구 결과가 1만 토큰을 넘으면 경고가 뜨고, 기본 한도는 2만 5천 토큰입니다. 한도를 바꿔야 한다면 `MAX_MCP_OUTPUT_TOKENS` 환경 변수를 사용합니다.
