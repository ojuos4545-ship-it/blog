# 클로드로 웹페이지 만들기 3단계 총정리

> 💡 **한 줄 요약:** 클로드로 웹페이지 만들기는
> 구체적으로 요청하고, 한 곳씩 다듬고, 게시해 공유하면 끝납니다.

[IMAGE: 썸네일 | 설명: 클로드로 웹페이지 만들기 3단계 총정리 대표 이미지]

"코딩은 하나도 모르는데 간단한 소개 페이지 하나만 있으면 좋겠어요"
하시는 분들을 위해 준비했습니다.
결론부터 말씀드리면, **클로드로 웹페이지 만들기**는
원하는 페이지를 자세히 요청하고, 고칠 곳을 하나씩 짚어 다듬은 뒤,
게시 버튼으로 링크를 만들면 끝납니다.

클로드는 대화창 옆에 아티팩트라는 별도 창을 열어
한 페이지짜리 웹사이트를 바로 보여 줍니다.
오늘 이 글 하나만 끝까지 읽으시면 요청부터 공유 링크까지
혼자서도 차근차근 해내실 수 있습니다.
기능과 버튼 이름은 [Claude 공식 도움말](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them)을
2026년 10월 30일에 확인해 정리했습니다.

---

## 🛠️ 시작하기 전에 준비할 것들

* **준비물:** 클로드 계정, 페이지에 넣을 내용 메모
* **설정:** Settings > Capabilities에서 파일 생성 기능 켜기
* **난이도:** 초급, 원하는 모습을 말로 설명할 수 있으면 충분합니다

아티팩트는 무료 요금제를 포함한 모든 요금제에서 만들 수 있습니다.
다만 공식 도움말 기준으로 파일 생성 기능이 켜져 있어야 하는데요.
새 화면에서는 이 항목이 `Create and edit files`라는 이름으로 보입니다.

아티팩트는 문서, 대시보드, 작은 도구처럼
대화 밖에서도 다시 쓸 만한 결과물을 담는 창입니다.
만든 것은 사이드바의 Artifacts 탭에 모여 있어서
나중에 다시 찾아 이어서 고칠 수도 있죠.

[IMAGE: 다이어그램 | 설명: 클로드 아티팩트로 웹페이지를 만드는 흐름: 요청하기, 다듬기, 게시하기]

---

## Step 1. 클로드에게 웹페이지는 어떻게 요청할까?

처음 시작할 때 가장 많이 실수하는 부분은 바로 요청을 한 줄로 끝내는 것입니다.
저도 처음엔 "카페 홈페이지 만들어줘"라고만 적었다가
어디서 본 듯한 평범한 페이지를 받았어요.
막연하게 부탁하면 결과도 막연해진다는 이야기가 정말 많더라고요.

요청에는 아래 네 가지를 함께 적어 주세요.

1. **무엇을:** 페이지 종류와 목적 (가게 소개, 행사 안내 등)
2. **누구에게:** 페이지를 볼 사람
3. **구성:** 위에서 아래로 들어갈 섹션 순서
4. **분위기:** 색감과 느낌, 참고하고 싶은 스타일

예를 들면 아래처럼 적을 수 있습니다.

```
동네 작은 빵집 소개 웹페이지를 한 페이지로 만들어줘.
보는 사람은 근처에 사는 주민이야.
구성은 가게 소개, 대표 메뉴 3개, 영업시간, 오시는 길 순서로 해줘.
분위기는 따뜻한 베이지 톤이고, 휴대폰에서도 보기 편하게 해줘.
사진은 아직 없으니 자리만 비워 둬.
```

[IMAGE: 포인트카드 | 설명: 클로드 웹페이지 요청 프롬프트에 넣을 네 가지: 무엇을, 누구에게, 구성, 분위기]

> 📌 **전문가 Tip:** 메뉴 이름, 가격, 주소처럼 정해진 내용은
> 처음부터 요청에 적어 주세요.
> 클로드가 그럴듯한 예시 문구로 채우면 나중에 하나하나 고쳐야 합니다.

---

## Step 2. 만든 웹페이지는 어떻게 다듬을까?

기본이 끝났다면 이제 마음에 들 때까지 다듬어 볼 차례입니다.
고치는 방법은 간단해요.
대화창에 바꾸고 싶은 점을 말하면 클로드가 같은 아티팩트를 고쳐 줍니다.

하지만 여기서 막히는 분이 꽤 많습니다.
버튼 색 하나만 바꿔 달라고 했는데
제목이나 배치까지 함께 바뀌어 버렸다는 후기가 자주 보이더라고요.
그래서 저는 아래 세 가지를 지키며 요청합니다.

* 고칠 곳을 화면에 보이는 문구로 정확히 짚기
* 한 번에 한 가지만 부탁하기
* "나머지는 그대로 둬"를 꼭 덧붙이기

```
"영업시간" 섹션의 배경색만 연한 초록으로 바꿔줘.
나머지 섹션과 글자는 그대로 둬.
```

[IMAGE: 포인트카드 | 설명: 클로드 아티팩트 웹페이지를 고칠 때 지킬 세 가지 수정 요청 요령]

고치다가 이전 모습이 더 낫다 싶을 때도 있죠.
공식 도움말에 따르면 앞서 보낸 메시지를 고쳐 보내면
대화가 갈래로 나뉘어 원래 결과물을 잃지 않고 새로 시도할 수 있습니다.

### 화면이 비거나 이미지가 안 보일 때는?

아티팩트에 오류가 나면 `Try fixing with Claude` 버튼이 뜹니다.
누르면 클로드가 직접 고쳐 보는데요,
공식 도움말도 항상 고쳐진다고 보장하지는 않습니다.

인터넷의 이미지 주소를 넣었는데 그림이 안 뜨거나
화면이 하얗게 비어 버렸다는 분도 많더라고요.
아티팩트 창은 보안 때문에 외부에서 불러오는 파일을
제한하는 경우가 있다는 설명이 여러 곳에서 반복됩니다.

이럴 때는 "외부 라이브러리나 이미지 없이
한 파일 안에서 동작하게 다시 만들어줘"라고 요청해 보세요.
사진 자리는 색 상자로 비워 두고,
마지막에 직접 넣는 편이 마음이 편합니다.

---

## Step 3. 완성한 웹페이지는 어떻게 공유할까?

페이지가 완성됐다면 이제 다른 사람에게 보여 줄 차례입니다.
대화에서 만든 아티팩트는 `Publish` 버튼을 누르고,
공개 링크를 복사해 보내면 됩니다.
게시는 무료, Pro, Max 요금제에서 쓸 수 있습니다.

링크를 받은 사람은 클로드 계정이 없어도 페이지를 보고 쓸 수 있습니다.
Team이나 Enterprise 요금제라면 `Publish` 대신
`Share & copy link`가 보이고, 기본으로 조직 안에서만 공유되죠.

많은 분들이 궁금해하시는 공유 방법을 표로 정리했습니다.

| 방법 | 장점 👍 | 주의점 👎 |
| :--- | :--- | :--- |
| **게시 링크** | 버튼 하나로 바로 공유 | 링크를 아는 누구나 볼 수 있음 |
| **임베드 코드** | 내 사이트 안에 넣어 보여 줌 | 허용할 사이트 주소를 따로 적어야 함 |
| **코드 내려받기** | 원하는 곳에 직접 올릴 수 있음 | 올릴 곳을 따로 준비해야 함 |

임베드는 게시한 뒤 `Get embed code`를 눌러
`Allowed domains` 칸에 허용할 사이트 주소를 쉼표로 나눠 적습니다.
게시를 취소하는 `Unpublish`는 신중하게 누르세요.
한 번 취소한 아티팩트는 다시 게시할 수 없어서 새로 만들어야 합니다.

[IMAGE: 비교표 | 설명: 클로드 아티팩트 웹페이지 공유 방법 비교: 게시 링크, 임베드 코드, 코드 내려받기]

하지만 중요한 건 빨리 공유하는 것이 아니라
**올려도 되는 내용만** 담는 것이겠죠.
게시 링크는 아는 사람이면 누구나 열 수 있으니
개인 연락처나 내부 자료는 넣기 전에 한 번 더 확인해 주세요.

한 페이지를 넘어 여러 페이지짜리 사이트로 키우고 싶다면
클로드 코드로 넘어가는 분이 많습니다.
이때 처음 보는 용어가 많아 낯설게 느껴질 수 있는데요,
다음 글에서 그 용어들을 쉽게 풀어 정리해 보겠습니다.

---

## 4. 마무리

오늘은 클로드로 웹페이지 만들기를
요청하기, 다듬기, 공유하기의 3단계로 알아보았습니다.
요청은 자세하게, 수정은 한 곳씩, 공유는 `Publish` 하나만
기억하셔도 첫 페이지는 충분히 완성하실 수 있습니다.

처음에는 내 소개 페이지처럼 작은 것부터 만들어 보세요.
작은 페이지 하나가 다음 도전을 훨씬 가볍게 만들어 주는 법이죠!

여러분은 어떤 웹페이지를 가장 먼저 만들어 보고 싶으신가요?
궁금한 점은 언제든 댓글로 남겨주세요. 감사합니다!
