1. 클로드 코드 요금제는 어떤 게 있을까?

클로드 코드는 claude.ai 구독에 함께 들어 있는 기능이라
따로 결제할 필요는 없습니다.
다만 무료(Free) 요금제에는 포함되지 않아서
최소 Pro 이상을 구독해야 하죠.

많은 분들이 궁금해하시는 가격부터 표로 정리했습니다.
(웹 결제 기준 달러 가격이고, 앱 결제는 다를 수 있습니다.)

2. 사용량 한도는 어떻게 계산될까?

클로드 코드 사용량 한도는 두 겹으로 걸려 있습니다.
하나는 5시간마다 초기화되는 세션 한도이고,
다른 하나는 일주일마다 초기화되는 주간 한도입니다.
한도를 메시지 몇 개처럼 숫자로 공개하지는 않는데요.

여기서 꼭 기억할 점은 채팅과 클로드 코드가 한도를 나눠 쓴다는 것입니다.
claude.ai 채팅, 데스크톱 앱, 클로드 코드에서 쓴 양이
모두 같은 한도에 함께 쌓이죠.

저도 오전에 채팅으로 자료를 정리하고 오후에 클로드 코드를 켰다가,
한도가 이미 꽤 줄어 있어서 놀란 적이 있어요.
두 곳이 따로 계산되는 줄 아는 분이 많더라고요.

그렇다면 사용량은 왜 생각보다 빨리 닳을까요?
공식 문서와 도움말이 꼽는 원인은 아래와 같습니다.

• 오래 열어 둔 긴 대화 (요청마다 대화 전체를 다시 보냄)
• Opus 같은 상위 모델과 높은 생각 깊이(effort) 설정
• MCP 같은 도구와 커넥터 사용
• 서브에이전트와 반복 예약 작업

Pro로 큰 작업을 맡기면 생각보다 빨리
한도 안내가 뜬다는 후기가 많더라고요.
저도 처음엔 여러 파일을 한꺼번에 고치게 했다가 금방 한도에 닿았어요.

클로드 코드는 요청마다 파일 내용과 도구 결과,
여러 단계의 추론을 함께 주고받기 때문입니다.
공식 문서도 디버깅 한 번이
하루치 채팅보다 많이 쓸 수 있다고 설명합니다.

3. 한도에 걸리면 어떻게 해야 할까?

세션 한도나 주간 한도에 닿으면
You've hit your session limit 같은 안내와
초기화 시각이 함께 나옵니다.
이때 할 수 있는 일은 크게 네 가지입니다.

1. 안내된 초기화 시각까지 기다립니다.
2. 상위 요금제로 올립니다. (Pro는 Max 5x로, Max 5x는 Max 20x로)
3. /usage-credits로 사용량 크레딧을 켭니다.
4. Console 계정으로 바꿔 API 크레딧으로 씁니다.

모델만 바꾸면 풀릴 거라 생각하기 쉬운데요.
세션 한도와 주간 한도는 모든 모델에 함께 걸려 있어서
모델을 바꿔도 풀리지 않습니다.
"Opus 한도"처럼 특정 모델 한도라면 다른 모델로 바꿔 이어 갈 수 있습니다.

【사진 04】

사용량 크레딧은 한도를 넘긴 뒤에도
작업을 이어 갈 수 있게 해 주는 기능입니다.

그래서 claude.ai의 Settings > Usage에서
월 지출 한도를 함께 정해 두시길 권합니다.

한도가 풀린 뒤 멈춘 작업을 자동으로 이어 가게 할 수 있습니다.
언제 자동으로 기다릴지는 /rate-limit-options에서 고르면 됩니다.

4. 사용량은 어디서 확인하고 어떻게 아낄까?

사용량 확인은 대화창에 /usage를 입력하면 됩니다.
구독 중이라면 요금제 사용량 막대와 활동 통계,
어디에 많이 썼는지 보여 주는 분석까지 한 화면에 나옵니다.
(d나 w 키로 최근 24시간과 7일을 오갈 수 있습니다.)

이때 맨 위 Session 칸의 달러 금액은
API 사용자를 위한 추정치라 구독 청구액과는 관계가 없습니다.
분석 결과는 이 컴퓨터의 기록으로 계산해서
다른 기기나 claude.ai 사용량은 빠져 있다는 점도 알아 두세요.

/status도 함께 보세요.
지금 구독으로 쓰는지, API 키로 쓰는지 알려 줍니다.

환경 변수에 ANTHROPIC_API_KEY를 넣어 둔 채 쓰다가
구독이 아니라 API 요금으로 청구되는 경우가 꽤 많더라고요.
저도 /status에서 인증 방식을 보고 나서야 원인을 알았어요.

API 키가 있으면 한 번 승인한 뒤부터 구독보다 먼저 쓰이고,
-p 옵션으로 실행하면 묻지도 않고 키를 씁니다.
구독으로 돌아가려면 unset ANTHROPIC_API_KEY로 키를 지우면 됩니다.

결제 방식장점 👍주의점 👎
구독 (Pro·Max)정액이라 요금 예측이 쉬움5시간·주간 한도가 있음
API (Console)정액 한도 없이 쓴 만큼 결제많이 쓰면 비용이 빠르게 커짐
【사진 05】

API로 쓰면 얼마나 나올까요?
공식 문서에 따르면 기업 환경에서는 개발자 1인당
활동일 하루 약 13달러, 한 달 150~250달러 수준입니다.
매일 오래 쓴다면 Max 구독이 계산하기 편한 이유죠.

사용량을 아끼는 습관은 아래 다섯 가지면 충분합니다.

• 다른 작업으로 넘어갈 땐 /clear로 새로 시작
• 대부분의 코딩은 Sonnet, 복잡한 설계만 Opus
• 간단한 작업은 /effort로 생각 깊이 낮추기
• 쓰지 않는 MCP 서버는 /mcp에서 끄기
• "코드 개선해줘" 대신 파일과 함수를 콕 집어 요청
