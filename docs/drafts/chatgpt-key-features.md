## 1. 챗GPT 핵심 기능, 한눈에 보면?

다섯 가지 기능을 먼저 표로 정리했습니다.
요금제별 한도는 자주 바뀌니 대략적인 흐름만 보시면 됩니다.

| 기능 | 이럴 때 써요 | 무료 계정 |
| :--- | :--- | :--- |
| **웹 검색** | 최신 소식,<br>출처가 필요할 때 | 사용 가능 |
| **파일·사진 분석** | PDF 요약,<br>사진 속 글자 읽기 | 횟수 제한 |
| **이미지 생성** | 썸네일, 그림 초안 | 횟수 제한 |
| **음성 대화** | 손이 바쁠 때,<br>말하기 연습 | 횟수 제한 |
| **메모리·프로젝트** | 내 정보 기억,<br>주제별 정리 | 범위 제한 |

표에서 보듯 무료 계정도 기능 자체는 대부분 열려 있습니다.
다만 하루에 쓸 수 있는 양이 정해져 있어서,
많이 쓰는 기능이 생기면 그때 요금제를 고민해도 늦지 않죠.

## 2. 검색과 파일 분석은 어떻게 쓸까?

먼저 정보를 찾고 정리하는 두 가지 기능입니다.
챗GPT를 업무에 쓰는 분들이 가장 자주 손이 가는 기능이기도 한데요.

### 기능 1. 웹 검색

챗GPT는 최신 정보가 필요한 질문이면 웹을 검색해서 답하고,
답변에 출처 링크를 함께 붙여 줍니다.
확실히 검색하게 하고 싶다면 요청에 그렇게 적으면 됩니다.

```
이번 주 서울 날씨와 미세먼지 전망을 검색해서 출처와 함께 알려줘
```

여기서 꼭 챙길 부분은 출처 링크를 직접 열어 보는 습관입니다.
저도 처음엔 그럴듯한 답을 그대로 믿었다가,
링크를 열어 보니 그런 내용이 없어서 다시 찾은 적이 있어요.
이런 일을 겪었다는 이야기가 커뮤니티에 꽤 자주 보이더라고요.

[IMAGE: 포인트카드 | 설명: 챗GPT 웹 검색 기능 쓰는 법과 출처 확인 요령]

### 기능 2. 파일·사진 분석

PDF, 문서, 사진을 올리면 내용을 읽고 정리해 줍니다.
긴 보고서 요약, 영수증 사진의 글자 정리,
표 데이터를 보기 좋게 바꾸는 일에 특히 편하죠.

* **PDF·문서:** 핵심만 요약하거나 질문에 답하기
* **사진:** 사진 속 글자를 읽어 옮기기
* **표·데이터:** 내용을 정리해 표로 다시 만들기

[IMAGE: 포인트카드 | 설명: 챗GPT 파일·사진 분석 기능으로 할 수 있는 일 PDF 요약, 사진 글자 읽기, 표 정리]

> 📌 **전문가 Tip:** 개인정보나 회사 기밀이 담긴 파일은 올리기 전에
> 이름, 연락처 같은 민감한 부분을 지우고 올리는 편이 안전합니다.

## 3. 이미지 생성과 음성 대화는 어떨까?

이번에는 글자가 아닌 그림과 목소리로 쓰는 기능입니다.
처음 써 보면 가장 신기하게 느끼는 부분이기도 하죠.

### 기능 3. 이미지 생성

원하는 그림을 말로 설명하면 이미지를 만들어 줍니다.
한 번에 마음에 들지 않으면
"배경만 밝게 바꿔줘"처럼 이어서 고쳐 달라고 하면 됩니다.

예전에는 이미지 속 한글이 깨져서 나온다는 불만이 많았는데요.
저도 썸네일 문구를 넣었다가 글자가 뭉개져서
글자는 따로 편집해 넣곤 했어요.
2026년 4월에 공개된 새 이미지 모델부터는
한글 표기가 크게 나아졌다고 발표됐습니다.

[IMAGE: 포인트카드 | 설명: 챗GPT 이미지 생성 기능 요청 예시와 수정 요청 방법]

### 기능 4. 음성 대화

휴대폰 앱 입력창의 음성 아이콘을 누르면
말로 묻고 말로 답을 듣는 음성 대화가 시작됩니다.
운전이나 요리처럼 손이 바쁠 때, 외국어 말하기를 연습할 때 좋습니다.
무료 계정은 쓸 수 있는 시간이 제한되어 있으니
긴 대화는 글로 이어 가는 편이 넉넉합니다.

## 4. 메모리와 프로젝트는 무엇이 다를까?

### 기능 5. 메모리와 프로젝트

메모리는 내가 알려 준 정보를 기억해 다음 대화에 쓰는 기능입니다.
"나는 초등학생 아이를 키우고 있어"라고 해 두면
이후 답변을 그에 맞춰 주는 식이죠.
프로젝트는 대화, 파일, 지시 사항을 주제별 폴더로 묶어 두는 기능이고,
2025년 9월부터 무료 계정에서도 쓸 수 있습니다.

메모리는 오래 쓰면 저장 공간이 가득 찰 수 있습니다.
저도 어느 날 메모리가 가득 찼다는 안내를 보고
무엇을 지워야 할지 몰라 한참 들여다봤어요.
같은 안내를 보고 당황했다는 글이 꽤 많더라고요.

이럴 때는 설정의 개인 맞춤(Personalization) 메뉴에서
저장된 메모리를 하나씩 보고 필요 없는 것만 지우면 됩니다.
채팅을 지워도 그 대화에서 저장된 메모리는 남으니,
메모리는 따로 지워야 합니다.

[IMAGE: 다이어그램 | 설명: 챗GPT 메모리 관리 순서: 저장 확인, 필요 없는 메모리 삭제, 임시 채팅 활용]

하지만 중요한 건 메모리를 아예 끄는 것이 아니라
**기억해도 되는 것만 남기는 것**이겠죠.
메모리 없이 대화하고 싶을 때는 임시 채팅을 쓰면
기억을 불러오지도, 새로 저장하지도 않습니다.
