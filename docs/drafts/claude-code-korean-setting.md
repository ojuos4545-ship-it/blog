# 클로드 코드 한국어 설정 방법 3단계

> 💡 **한 줄 요약:** 클로드 코드 한국어 설정은 settings.json의
> `language` 한 줄과 CLAUDE.md 한 문장이면 충분합니다.

[IMAGE: 썸네일 | 설명: 클로드 코드 한국어 설정 방법 3단계 대표 이미지]

"한국어로 물어봤는데 답은 자꾸 영어로 와요"
하시는 분들을 위해 준비했습니다.
결론부터 말씀드리면, **클로드 코드 한국어 설정**은
settings.json에 `"language": "korean"`을 넣고,
CLAUDE.md에 한국어 답변 규칙을 한 줄 더 적으면 됩니다.

저도 처음엔 질문 끝에 매번 "한국어로 답해줘"를
붙여 가며 썼어요.
이렇게 쓰다가 설정 방법을 찾아보는 분이 꽤 많더라고요.

오늘 이 글 하나만 끝까지 읽으시면 설정 파일 수정부터
중간에 영어로 돌아올 때의 대처까지 혼자 하실 수 있습니다.
설정 이름과 파일 위치는
[Claude Code 공식 문서](https://code.claude.com/docs/en/settings)를
2026년 11월 1일에 확인해 정리했습니다.

---

## 🛠️ 시작하기 전에 준비할 것들

* **준비물:** 클로드 코드 설치, 메모장 같은 텍스트 편집기
* **소요 시간:** 파일 두 개만 고치면 되니 금방 끝납니다
* **난이도:** 초급, 파일을 열어 글자를 고칠 수 있으면 충분합니다

방법은 두 갈래입니다.
settings.json은 클로드 코드가 읽는 설정 파일이고,
CLAUDE.md는 클로드에게 주는 안내문 파일인데요.
첫 번째로 기본 언어를 정하고, 두 번째로 규칙을 보강한 뒤,
마지막에 제대로 적용됐는지 확인하는 순서로 진행합니다.

[IMAGE: 다이어그램 | 설명: 클로드 코드 한국어 설정 3단계 흐름: settings.json, CLAUDE.md, 적용 확인]

## Step 1. settings.json에 language는 어떻게 넣을까?

처음 설정할 때 가장 많이 헷갈리는 부분은 바로 파일 위치입니다.
설치만 해서는 설정 파일이 생기지 않기 때문에
파일이 없다면 직접 만들어야 하죠.

아래 순서대로 차근차근 따라와 주세요.

1. 홈 폴더의 `.claude` 폴더를 엽니다.
2. `settings.json` 파일을 열거나 새로 만듭니다.
3. 아래 내용을 넣고 저장합니다.

```json
{
  "language": "korean"
}
```

이미 다른 설정이 들어 있다면 중괄호 안에 한 줄만 추가하고,
앞 줄 끝에 쉼표를 붙여 주세요.
설정 파일은 엄격한 JSON 형식이라서 `//` 주석이나
마지막 항목 뒤의 쉼표가 있으면 오류로 처리됩니다.

파일을 어디에 두느냐에 따라 적용되는 범위가 달라집니다.
많은 분들이 궁금해하시는 부분이라 표로 정리했습니다.

| 파일 위치 | 적용 범위 | 이런 분께 |
| :--- | :--- | :--- |
| `~/.claude/settings.json` | 내 컴퓨터의 모든 프로젝트 | 혼자 쓰는 대부분의 경우 |
| `.claude/settings.json` | 이 프로젝트를 쓰는 모든 사람 | 팀 전체가 한국어로 쓸 때 |
| `.claude/settings.local.json` | 이 프로젝트의 나에게만 | 팀 설정은 두고 나만 바꿀 때 |

[IMAGE: 포인트카드 | 설명: 클로드 코드 한국어 설정을 넣는 settings.json 파일 위치 3곳 정리]

> 📌 **전문가 Tip:** `language` 값은 정해진 목록이 없고,
> 적은 그대로 클로드에게 "이 언어로 답하라"는 지시로 전달됩니다.
> 클로드 코드가 값을 검사하지 않아서 철자가 틀려도 오류가 나지 않으니
> `korean` 철자를 한 번 더 확인해 보세요.

## Step 2. CLAUDE.md로 한 번 더 고정하려면?

기본이 끝났다면 이제 규칙을 한 겹 더 씌울 차례입니다.
CLAUDE.md는 세션이 시작될 때마다 읽히는 안내문이라서
답변 말투나 형식처럼 자세한 요청을 적기 좋습니다.

모든 프로젝트에 적용하려면 홈 폴더의 `~/.claude/CLAUDE.md`에,
특정 프로젝트에만 적용하려면 프로젝트 폴더의 `CLAUDE.md`에 적습니다.
클로드 코드 안에서 `/memory`를 입력하면
이 파일들을 바로 열어 고칠 수도 있어요.

```
## 언어
- 모든 답변과 설명은 한국어로 작성한다.
- 코드, 명령어, 파일 이름은 원래 표기를 그대로 둔다.
```

공식 문서도 CLAUDE.md는 강제 설정이 아니라 참고 내용으로 읽히고,
지시가 구체적이고 짧을수록 더 꾸준히 따른다고 설명합니다.
그래서 "한국어로" 한 마디보다 무엇을 한국어로 쓸지
범위를 함께 적어 두는 편이 낫습니다.

[IMAGE: 포인트카드 | 설명: CLAUDE.md에 클로드 코드 한국어 답변 규칙을 적는 위치와 예시 문장]

## Step 3. 중간에 영어로 돌아올 때는 어떻게 할까?

설정을 마쳤다면 먼저 적용 여부부터 확인해 보세요.
클로드 코드에서 `/status`를 입력하면
`Setting sources` 줄에 불러온 설정 파일 목록이 나옵니다.
여기에 `User settings`가 보이면 홈 폴더 설정이 읽힌 것입니다.

그런데 설정을 다 해 둬도 작업 도중에 영어 답변이
섞여 나온다는 이야기가 많습니다.
특히 git 명령처럼 영어로만 된 결과를 읽은 직후에
언어가 바뀌었다는 사례가 여러 곳에서 보이더라고요.
이럴 때는 아래 순서로 점검해 보세요.

* 대화창에 "한국어로 답해줘"라고 한 번 다시 요청합니다
* `/status`에서 설정 파일이 제대로 읽혔는지 확인합니다
* CLAUDE.md의 언어 규칙을 더 짧고 구체적으로 고칩니다

두 방법의 차이도 표로 정리했습니다.

| 방법 | 장점 👍 | 단점 👎 |
| :--- | :--- | :--- |
| **settings.json** | 한 줄로 끝나고 세션 제목까지 맞춰짐 | 답변 형식 같은 세부 규칙은 못 적음 |
| **CLAUDE.md** | 무엇을 한국어로 쓸지 자세히 적음 | 참고 내용이라 길면 효과가 약해짐 |

### VS Code나 데스크톱 앱에서도 똑같이 될까?

네, 터미널과 VS Code, JetBrains 확장, 데스크톱 앱은
같은 설정 파일을 읽습니다.
다만 VS Code 채팅 창과 데스크톱 앱에서는 `/config` 메뉴가 열리지 않으니
settings.json 파일을 직접 고치는 방법을 쓰시면 됩니다.

하지만 중요한 건 답변 언어와 화면 표시가 서로 다른 문제라는 점이겠죠.
`language`가 바꾸는 것은 클로드의 답변과
음성 받아쓰기 언어, 자동으로 붙는 세션 제목입니다.
한글이 네모나 이상한 기호로 보인다면 언어 설정이 아니라
터미널의 글자 인코딩 쪽을 따로 살펴봐야 합니다.

`"language": "korean"` 한 줄로 시작하고,
부족하면 CLAUDE.md로 보강한다고 기억하시면 됩니다.
