# 클로드 코드 이미지 첨부 사용법 3단계

> 💡 **한 줄 요약:** 클로드 코드 이미지 첨부는 이미지 넣기,
> 요청하기, 안 될 때 점검하기의 3단계면 끝납니다.

[IMAGE: 썸네일 | 설명: 클로드 코드 이미지 첨부 사용법 3단계 대표 이미지]

"오류 화면을 캡처했는데 어떻게 보여 줘야 할지 모르겠어요"
하시는 분들을 위해 준비했습니다.
결론부터 말씀드리면, **클로드 코드 이미지 첨부**는
드래그, 붙여넣기, 파일 경로 입력 중 하나만 고르면 됩니다.

글로 설명하기 어려운 오류 화면이나 디자인 시안은
이미지로 보여 주는 쪽이 훨씬 빠릅니다.
오늘 이 글 하나만 끝까지 읽으시면 캡처 한 장을 붙여서
질문하는 데까지 혼자 하실 수 있습니다.
방법과 단축키는
[Claude Code 공식 문서](https://code.claude.com/docs/en/common-workflows)를
2026년 11월 5일에 확인해 정리했습니다.

[IMAGE: 다이어그램 | 설명: 클로드 코드 이미지 첨부 3단계 흐름: 이미지 넣기, 요청하기, 점검하기]

---

## 🛠️ 시작하기 전에 준비할 것들

* **준비물:** 클로드 코드 설치, 첨부할 이미지나 캡처
* **소요 시간:** 이미지 한 장 기준으로 금방 끝납니다
* **난이도:** 초급, 단축키만 눌러 보면 충분합니다

캡처한 화면은 클립보드(복사한 내용이 잠시 저장되는 곳)에
담아 두면 바로 붙여 넣을 수 있습니다.
이미지 파일로 저장해 둔 경우에는
파일이 어디에 있는지만 알아 두세요.

---

## Step 1. 클로드 코드 이미지 첨부는 어떻게 할까?

이미지를 넣는 방법은 공식 문서 기준으로 세 가지입니다.
아래 순서대로 차근차근 따라와 주세요.

1. 이미지를 클로드 코드 창으로 끌어다 놓습니다.
2. 이미지를 복사한 뒤 입력창에서 `Ctrl+V`를 누릅니다.
3. 요청 문장에 이미지 파일 경로를 직접 적습니다.

[IMAGE: 포인트카드 | 설명: 클로드 코드 이미지 첨부 3가지 방법: 드래그 앤 드롭, 붙여넣기, 파일 경로]

처음 시작할 때 가장 많이 막히는 부분은 바로 붙여넣기 키입니다.
저도 처음엔 평소 습관대로 키를 눌렀다가
이미지가 안 붙어서 한참 헤맸어요.
특히 맥에서는 `Cmd+V`가 글자 붙여넣기로 처리되는 경우가 많더라고요.

공식 문서에는 `Cmd+V`가 iTerm2(맥용 터미널 앱)에서만 적혀 있습니다.
운영체제별 키는 아래 표로 정리했습니다.

| 환경 | 이미지 붙여넣기 키 |
| :--- | :--- |
| **macOS, Linux** | `Ctrl+V` |
| **iTerm2** | `Cmd+V`도 가능 |
| **Windows** | `Alt+V` |
| **WSL** | `Ctrl+V`, `Alt+V` 모두 가능 |

[IMAGE: 비교표 | 설명: 클로드 코드 이미지 첨부 시 환경별 붙여넣기 키: macOS, iTerm2, Windows, WSL]

WSL은 윈도우 안에서 리눅스를 쓰게 해 주는 기능입니다.
세 번째 방법인 파일 경로는 아래처럼 적으면 됩니다.

```
이 이미지를 분석해줘: /path/to/your/image.png
```

> 📌 **전문가 Tip:** 한 대화에 이미지를 여러 장 넣어도 됩니다.
> 공식 문서도 한 대화에서 여러 이미지를 다룰 수 있다고 안내합니다.

---

## Step 2. 첨부한 이미지로 무엇을 요청할까?

붙여넣기에 성공하면 입력창에 `[Image #1]` 같은 표시가 생깁니다.
이 표시는 커서 위치에 들어가서,
여러 장을 넣었을 때 어느 이미지를 말하는지 짚어 주기 좋아요.

이제 이미지로 알고 싶은 것을 한 문장으로 요청해 보세요.
공식 문서의 예시도 오류 화면의 원인을 묻거나,
디자인 시안에 맞는 CSS를 만들어 달라는 식입니다.

```
이 화면에서 나온 오류의 원인이 뭔지 알려줘
```

```
이 시안과 비슷하게 보이는 CSS를 만들어줘
```

[IMAGE: 포인트카드 | 설명: 클로드 코드 이미지 첨부 후 요청하는 순서와 프롬프트 예시]

> 📌 **전문가 Tip:** 클로드가 답변에서 `[Image #1]`을 언급하면
> 그 표시를 `Cmd+클릭`(맥) 또는 `Ctrl+클릭`(윈도우, 리눅스)해
> 기본 이미지 뷰어로 열어 볼 수 있습니다.

---

## Step 3. 클로드 코드 이미지 첨부가 안 될 땐 어떻게 할까?

`Ctrl+V`를 눌렀는데 아무 반응이 없어서 당황하는 분이 많더라고요.
윈도우 환경에서는 터미널이 `Ctrl+V`를 자기 글자 붙여넣기에 써서
클로드 코드까지 키가 전달되지 않는 경우가 있습니다.
이때는 `Alt+V`를 눌러 보세요.

원격 컴퓨터에 SSH로 접속해서 쓰는 경우에도
붙여넣기가 안 된다는 보고가 꽤 보입니다.
이럴 때는 붙여넣기에 매달리지 말고
이미지 파일을 경로로 알려 주는 쪽이 훨씬 덜 헤맵니다.
증상별로 확인할 것을 표로 모았습니다.

| 증상 | 확인할 것 |
| :--- | :--- |
| **Ctrl+V에 반응 없음** | `Alt+V`로 붙여넣기 |
| **맥에서 글자만 붙음** | `Ctrl+V`로 붙여넣기 |
| **SSH 접속 중 실패** | 파일 경로로 알려 주기 |
| **붙여넣기가 모두 실패** | 드래그 앤 드롭 시도 |

[IMAGE: 비교표 | 설명: 클로드 코드 이미지 첨부가 안 될 때 증상별 확인 항목 정리]

붙여넣기와 드래그 앤 드롭은 터미널에 따라 동작이 다를 수 있습니다.
그래서 한 가지가 막히면 다른 방법으로 바로 넘어가는 편이 빠릅니다.
파일 경로 입력은 공식 문서에 적힌 방법 중에서도
환경을 덜 타는 쪽이라 마지막 보루로 두기 좋아요.
