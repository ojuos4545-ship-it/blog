2. 클로드 코드는 클로드와 무엇이 다를까?

클로드는 묻고 답하는 AI 비서

클로드는 claude.ai 웹사이트와 앱에서 쓰는 대화형 AI입니다.
글쓰기, 요약, 번역, 아이디어 정리처럼
말로 주고받는 일을 폭넓게 도와주죠.

코드를 물어보면 답으로 코드를 보여 주지만,
기본적으로 내 컴퓨터의 프로젝트 폴더를 열어 보지는 못합니다.
그래서 받은 코드를 파일에 옮기고 실행하는 일은
사람이 직접 해야 합니다.

클로드 코드는 직접 손을 움직이는 에이전트

공식 문서는 클로드 코드를 코드베이스를 읽고,
파일을 고치고, 명령을 실행하는 에이전트형 코딩 도구라고 소개합니다.
"테스트를 짜고 돌려서 실패하면 고쳐줘"처럼 목표를 주면
계획을 세워 여러 파일을 고치고 결과까지 확인합니다.

git과도 바로 이어져서 변경 내용을 정리하고
커밋 메시지를 쓰거나 PR을 여는 일까지 맡길 수 있어요.
복사와 붙여넣기를 오가던 일이 줄어든다는 점이
가장 크게 느껴지는 차이입니다.

3. 어디서 쓰고, 요금은 어떻게 다를까?

쓰는 곳: 채팅창 vs 작업 공간

클로드는 웹, 데스크톱 앱, iOS와 안드로이드 앱의 채팅창에서 씁니다.
클로드 코드는 처음엔 터미널 도구로 알려졌지만,
지금은 쓰는 곳이 꽤 넓어졌습니다.

• 터미널: 기능이 가장 많은 기본 형태
• IDE: VS Code 확장, JetBrains 플러그인
• 데스크톱 앱: 클로드 앱 안의 Code 탭
• 웹: claude.ai/code에서 설치 없이 실행

【사진 04】

데스크톱 앱은 한 앱 안에 채팅과 Code 탭이 함께 있어서
여기서 많이들 헷갈리시죠.
채팅 탭은 일반 클로드이고,
Code 탭을 눌러야 클로드 코드로 작업할 수 있습니다.

요금: 무료 플랜에는 클로드 코드가 없다

요금 페이지 기준으로 무료 플랜에서도 클로드 채팅은 쓸 수 있지만,
클로드 코드는 포함되지 않습니다.
무료 계정으로 설치부터 했다가
쓸 수 없다는 걸 뒤늦게 알았다는 분이 꽤 많더라고요.

플랜월 요금 (미국 기준)클로드 코드
Free0달러포함 안 됨
Pro20달러 (연간 결제 시 월 17달러)포함
Max100달러부터포함, Pro보다 넉넉한 사용량
Team·Enterprise좌석당 요금포함

같은 한도에서 함께 빠져나갑니다.
저도 클로드 코드에 일을 길게 맡긴 날에는
채팅에서 쓸 여유가 확 줄어 있어서 당황한 적이 있어요.

4. 내 상황엔 무엇을 써야 할까?

많은 분들이 결국 궁금해하시는 부분입니다.
둘 중 하나만 골라야 하는 건 아니고,
하려는 일에 맞춰 나눠 쓰면 됩니다.

• 클로드가 맞는 일: 글쓰기, 요약, 번역, 개념 질문
• 클로드 코드가 맞는 일: 기능 추가, 버그 수정, 테스트
• 둘 다 쓰는 일: 채팅으로 계획, 클로드 코드로 구현
