# 챗GPT 에이전트 뜻과 사용법 4단계

> 💡 **한 줄 요약:** 에이전트는 답 대신 일을 끝내 주는 AI이고,
> 지금은 Work 모드를 골라 결과물 형태로 맡기면 됩니다.

[IMAGE: 썸네일 | 설명: 챗GPT 에이전트 뜻과 사용법 4단계 대표 이미지]

"에이전트 모드를 쓰려고 들어갔는데 메뉴가 안 보여요"
하시는 분들을 위해 준비했습니다.
결론부터 말씀드리면, **챗GPT 에이전트**는 질문에 답만 하는 대신
스스로 계획을 세우고 도구를 써서 일을 끝내 주는 기능입니다.
예전 '에이전트 모드'의 역할은 지금 **Work(워크)**가 이어받았습니다.

그래서 요즘은 대화창 위쪽 전환 메뉴에서 Work를 고르고,
원하는 결과물을 구체적으로 적어 맡기면 됩니다.
오늘은 에이전트의 뜻부터 Work로 일을 맡기는 4단계까지 짚어볼게요.
내용은 오픈AI 발표와 도움말 안내를 바탕으로
2026년 11월 기준으로 정리했습니다.

---

## 🔍 챗GPT 에이전트 뜻은 무엇일까?

에이전트(agent)는 원래 '대신 일을 처리해 주는 사람'이라는 뜻입니다.
AI에서는 목표를 받으면 할 일을 단계로 나누고,
검색이나 브라우저, 파일 같은 도구를 직접 써서
끝까지 해내는 AI를 가리킵니다.

일반 대화는 내가 묻고 AI가 답하는 주고받기라면,
에이전트는 "이 일 좀 해 줘"라고 맡기는 방식이죠.
그래서 결과도 채팅 답변이 아니라 문서나 표 같은 완성본으로 받습니다.

[IMAGE: 다이어그램 | 설명: 챗GPT 에이전트가 요청을 계획, 실행, 결과물 순서로 처리하는 흐름]

### 에이전트 모드는 왜 안 보일까?

챗GPT의 에이전트 기능은 2025년 7월 '에이전트 모드'로 처음 나왔습니다.
웹사이트를 대신 조작하던 오퍼레이터와
자료를 깊이 찾아 주던 딥 리서치를 하나로 합친 기능이었는데요.
이후 2026년 7월 9일 오픈AI가 **ChatGPT Work**를 공개했고,
지금 도움말에는 기존 에이전트 대신 Work를 쓰라고 안내돼 있습니다.

저도 오랜만에 에이전트 모드를 쓰려고 메뉴를 열었다가
항목이 안 보여서 한참 찾았어요.
같은 일로 커뮤니티에 질문을 올린 분이 꽤 많더라고요.

| 구분 | 일반 대화 | Work 👍 |
| :--- | :--- | :--- |
| **하는 일** | 질문에 답하기 | 계획을 세우고<br>도구로 실행 |
| **결과물** | 채팅 답변 | 문서, 표, 발표 자료,<br>웹앱 |
| **쓰는 도구** | 검색, 파일 분석 | 앱 연결, 플러그인,<br>클라우드 브라우저 |
| **작업 시간** | 바로 답함 | 길면 몇 시간까지<br>이어서 작업 |

[IMAGE: 비교표 | 설명: 챗GPT 일반 대화와 에이전트 역할을 하는 Work의 차이 비교]

## 🛠️ 시작하기 전에 준비할 것들

* **준비물:** 챗GPT 계정, 맡길 일과 참고 자료
* **요금제:** 웹·모바일은 유료 요금제부터 쓸 수 있습니다
* **난이도:** 초급, 대화창에 요청을 적어 본 적이면 충분합니다

오픈AI 발표에 따르면 새 데스크톱 앱(맥·윈도우)에서는
무료 요금제도 Work를 쓸 수 있습니다.
다만 상위 요금제부터 차례로 열리고 있어서
계정마다 메뉴가 보이는 시기가 다를 수 있습니다.

---

## Step 1. Work 모드는 어떻게 켤까?

처음엔 메뉴 위치부터 헷갈리기 쉽습니다.
예전처럼 입력창의 도구 목록에서 에이전트를 찾는 게 아니라,
화면 위쪽의 전환 메뉴에서 모드를 바꾸는 방식입니다.
아래 순서대로 차근차근 따라와 주세요.

1. 챗GPT 웹이나 앱을 열고 새 대화를 시작합니다.
2. 화면 위쪽의 전환 메뉴에서 **Work**를 고릅니다.
3. 입력창에 맡길 일을 적고 보냅니다.

데스크톱 앱이라면 왼쪽 위 메뉴에서 ChatGPT를 먼저 고른 뒤,
같은 방법으로 위쪽 전환 메뉴에서 Work를 선택하면 됩니다.
데스크톱 앱에서는 내 컴퓨터의 폴더를 열어
그 안의 파일로 작업하게 할 수도 있죠.

[IMAGE: 포인트카드 | 설명: 챗GPT Work 모드를 켜고 첫 작업을 맡기는 순서]

---

## Step 2. 일은 어떻게 맡기면 좋을까?

기본이 끝났다면 이제 실제로 일을 맡겨 볼 차례입니다.
Work는 "알려 줘"보다 "만들어 줘"에 강한 기능이라서,
받고 싶은 결과물의 형태를 먼저 적는 것이 핵심입니다.

* **목표와 형식:** 무엇을 어떤 파일로 받을지 적기
* **참고 자료:** 볼 파일, 사이트, 조건을 함께 주기
* **확인 지점:** 어디서 멈추고 물어볼지 정하기

```
우리 동네 필라테스 학원 세 곳의 가격과 시간표를 찾아서 표로 정리하고, 예약하기 전에 나한테 먼저 확인받아줘
```

[IMAGE: 포인트카드 | 설명: 챗GPT Work에 일을 맡길 때 요청에 넣을 세 가지와 프롬프트 예시]

> 📌 **전문가 Tip:** 처음 맡기는 일이라면 Plan 모드로 시작해 보세요.
> 챗GPT가 필요한 내용을 묻고 단계별 계획을 먼저 보여 주는데,
> 계획을 고치거나 승인해야 작업이 시작됩니다.

---

## Step 3. 사이트 승인과 로그인은 어떻게 할까?

웹사이트를 돌아다녀야 하는 일이면 Work는 클라우드 브라우저를 씁니다.
내 컴퓨터가 아니라 원격에서 돌아가는 브라우저라서,
기기를 닫아도 작업이 이어집니다.
어떤 도구를 쓸지는 요청을 보고 챗GPT가 직접 고릅니다.

처음 가는 사이트는 방문하기 전에 기본으로 승인을 묻습니다.
사이트별 허용 여부는 설정의 클라우드 브라우저 메뉴에서 바꿀 수 있는데요.
모든 사이트를 자동으로 허용하는 설정도 있지만,
오픈AI도 권장하지 않으니 기본값을 그대로 두는 편이 안전합니다.

로그인이 필요한 사이트에서는 보안 로그인 창에
아이디와 비밀번호를 내가 직접 입력합니다.
2단계 인증도 직접 마쳐야 하고,
작업이 막히면 챗GPT가 화면 제어를 넘겨받아 달라고 요청합니다.

저도 처음엔 로그인 화면에서 작업이 멈춘 줄 알았는데,
제가 직접 로그인해 주길 기다리는 거였어요.
진행 화면에 요청 문구가 떠 있지 않은지 먼저 확인해 보세요.

[IMAGE: 포인트카드 | 설명: 챗GPT Work 클라우드 브라우저의 사이트 승인과 로그인 안전 수칙]

## Step 4. 결과는 어떻게 확인할까?

작업이 진행되는 모습은 대화 화면에서 그대로 볼 수 있습니다.
결과물이 나오면 바로 쓰지 말고,
챗GPT가 함께 남긴 출처와 내용을 한 번 확인해야 합니다.
특히 가격이나 날짜처럼 바뀌기 쉬운 정보는 원래 사이트에서 다시 보세요.

하지만 중요한 건 일을 많이 맡기는 것이 아니라
**확인할 수 있는 만큼만** 맡기는 것이겠죠.
결제나 예약처럼 되돌리기 어려운 일은
마지막 단계에서 꼭 내가 확인하도록 요청에 적어 두는 게 좋습니다.

사용량도 함께 살펴보세요.
저도 여러 사이트를 오가는 일을 맡겼을 때
남은 사용량이 생각보다 빨리 줄더라고요.
비슷한 글이 커뮤니티에 여러 번 올라와 있으니,
긴 작업은 범위를 좁혀서 나눠 맡기는 편이 낫습니다.

## 5. 마무리

오늘은 챗GPT 에이전트의 뜻과
지금 그 역할을 하는 Work 사용법을 알아보았습니다.
Work를 켜고, 결과물 형태로 요청하고,
사이트 승인과 로그인을 직접 챙긴 뒤 결과를 확인하면 됩니다.

처음에는 표 하나 만드는 작은 일부터 맡겨 보세요.
작은 일 하나를 맡겨 보는 경험이 쌓이면 손이 훨씬 가벼워지는 법이죠!
에이전트를 이해하는 데 도움이 되었기를 바랍니다.
