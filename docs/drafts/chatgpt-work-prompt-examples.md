> 형식 네 가지를 한 번에 적어야 바로 쓸 결과가 나옵니다.

[IMAGE: 썸네일 | 설명: 챗GPT 업무용 프롬프트 예시 10가지 대표 이미지]

안녕하세요, 여러분! 결론부터 말씀드리면,
**챗GPT 업무용 프롬프트**는 역할, 맥락, 요청, 형식을
한 번에 적어 줄 때 고칠 곳이 가장 적은 결과가 나옵니다.

회사에서 챗GPT를 쓰라는 말은 많이 듣는데,
막상 창을 열면 무엇을 어떻게 물어야 할지 막막하셨죠?
저도 처음엔 "보고서 써줘"처럼 한 줄만 적었다가
어디서 본 듯한 뻔한 답을 받곤 했어요.

목적과 형식을 알려 주지 않으면
평균적인 답이 돌아온다는 이야기가 정말 많더라고요.
[OpenAI 도움말](https://help.openai.com/en/articles/10032626-prompt-engineering-best-practices-for-chatgpt)도 프롬프트를 명확하고 구체적으로 쓰고,
충분한 맥락을 주라고 권합니다.

오늘은 메일, 요약, 회의록부터 엑셀 수식,
발표 준비까지 바로 복사해 쓸 수 있는 예시 10가지를 정리해 드리겠습니다.
대괄호 안만 내 상황으로 바꾸면 되니 바쁘신 분들도 금방 따라 하실 수 있어요.

## 1. 업무용 프롬프트는 어떻게 써야 할까?

예시를 보기 전에 공식부터 짚어볼게요.
좋은 업무 프롬프트에는 아래 네 가지가 들어갑니다.

* **역할:** 누구의 입장에서 답할지 (예: 10년 차 마케터)
* **맥락:** 지금 상황과 읽을 사람, 쓰는 목적
* **요청:** 정확히 해 달라는 일 하나
* **형식:** 분량, 말투, 표나 목록 같은 모양

[IMAGE: 포인트카드 | 설명: 챗GPT 업무용 프롬프트를 쓰는 공식: 역할, 맥락, 요청, 형식]

네 가지 중에서 가장 자주 빠지는 것은 맥락입니다.
같은 메일이라도 팀장에게 보내는지, 거래처에 보내는지에 따라
말투와 내용이 완전히 달라지기 때문이죠.

형식도 꼭 적어 주세요.
"표로", "3줄로", "존댓말로"처럼 모양을 정해 두면
결과를 다시 손보는 시간이 크게 줄어듭니다.

> 📌 **전문가 Tip:** 원하는 결과물의 예시가 있다면 함께 붙여 넣으세요.
> "이 메일과 비슷한 말투로"처럼 본보기를 주면
> 설명을 길게 쓰지 않아도 원하는 쪽으로 맞춰 줍니다.

## 2. 문서 작성에 쓰는 프롬프트 예시 5가지

직장인이 가장 많이 맡기는 일은 역시 글쓰기입니다.
메일부터 문장 교정까지 자주 쓰는 다섯 가지를 골랐습니다.

[IMAGE: 비교표 | 설명: 문서 작성용 챗GPT 업무 프롬프트 예시 5가지와 꼭 넣을 정보]

### 예시 1. 업무 메일 작성

```
너는 10년 차 영업 담당자야.
거래처 담당자에게 납품 일정이
[3일] 늦어진다는 메일을 써줘.
사과와 이유, 새 일정, 대안을 순서대로 넣고
5문장 안에서 정중한 존댓말로 써줘.
```

받는 사람과 꼭 들어가야 할 내용을 순서대로 적은 것이 핵심입니다.
결과가 딱딱하면 "조금 더 부드럽게"라고 한 줄만 덧붙이면 되죠.

### 예시 2. 긴 보고서 요약

```
아래 보고서를 바쁜 임원이 읽는다고 생각하고 요약해줘.
결론 한 줄, 핵심 근거 3가지, 남은 과제 순서로
불릿 목록을 만들어줘.
보고서에 없는 내용은 추가하지 마.

[보고서 붙여 넣기]
```

마지막 줄의 "없는 내용은 추가하지 마"가 중요합니다.
요약하면서 원문에 없는 말을 덧붙이는 일을 줄여 주거든요.

### 예시 3. 회의록 정리

```
아래 회의 메모를 회의록으로 정리해줘.
형식은 안건, 결정 사항, 할 일(담당자, 기한) 표로 하고,
결정되지 않은 내용은 '추후 논의'로 따로 모아줘.

[회의 메모 붙여 넣기]
```

메모가 엉성해도 괜찮습니다.
할 일과 담당자를 표로 나눠 달라고 하면 바로 공유할 수 있는 모양이 됩니다.

### 예시 4. 기획서 초안 구성

```
너는 기획팀 선임이야.
[사내 독서 모임 운영] 기획서의 목차를 만들어줘.
읽는 사람은 예산을 승인하는 팀장이고,
각 목차 아래에 들어갈 내용을 한 줄씩 적어줘.
```

처음부터 본문 전체를 쓰게 하기보다 목차를 먼저 받는 편이 좋습니다.
구성이 마음에 들면 "2번 항목만 자세히 써줘"처럼 나눠서 이어가면 되죠.

### 예시 5. 문장 교정과 말투 바꾸기

```
아래 공지문을 맞춤법과 띄어쓰기에 맞게 고쳐줘.
뜻은 바꾸지 말고, 고친 부분은 표로
'원래 문장, 고친 문장, 이유' 순서로 보여줘.

[공지문 붙여 넣기]
```

고친 이유까지 표로 받으면 어디가 바뀌었는지 한눈에 확인할 수 있습니다.
마음에 들지 않는 수정은 골라서 빼면 되니 훨씬 안심이 되죠.

## 3. 분석과 기획에 쓰는 프롬프트 예시 5가지

글쓰기 다음으로 많이 쓰는 분야는 숫자와 아이디어입니다.
엑셀 수식부터 발표 준비까지 다섯 가지를 모았습니다.

[IMAGE: 비교표 | 설명: 분석과 기획용 챗GPT 업무 프롬프트 예시 5가지와 꼭 넣을 정보]

### 예시 6. 엑셀 수식 만들기

```
엑셀에서 A열은 날짜, B열은 담당자, C열은 매출이야.
담당자별로 이번 달 매출 합계를 구하는 수식을 알려줘.
수식이 어떻게 동작하는지 초보자도 알게 한 줄씩 설명해줘.
```

열 구성을 먼저 알려 주는 것이 핵심입니다.
그래야 내 파일에 바로 붙여 넣을 수 있는 수식이 나옵니다.

### 예시 7. 데이터 해석

```
아래는 지난 6개월 문의 건수 표야.
눈에 띄는 변화 3가지를 찾고, 각각 가능한 원인을 적어줘.
확실하지 않은 원인은 '추정'이라고 표시해줘.

[표 붙여 넣기]
```

"추정이라고 표시해줘"를 넣으면 확인된 사실과 짐작을 나눠서 볼 수 있습니다.
보고서에 옮기기 전에 어느 부분을 검증할지도 바로 보이죠.

### 예시 8. 아이디어 브레인스토밍

```
너는 고객 경험 담당자야.
[온라인 쇼핑몰 재구매]를 늘릴 아이디어를 10개 내줘.
비용이 적게 드는 것부터 순서대로 정리하고,
각 아이디어의 예상 장점과 걸림돌을 한 줄씩 붙여줘.
```

아이디어는 처음부터 많이 받은 뒤 고르는 편이 좋습니다.
마음에 드는 두세 개를 골라 "실행 계획으로 바꿔줘"라고 이어가 보세요.

### 예시 9. 업무 우선순위 정리

```
아래는 이번 주 할 일 목록이야.
마감, 중요도, 걸리는 시간을 기준으로
'오늘, 이번 주, 미뤄도 됨' 세 그룹으로 나눠줘.
그렇게 나눈 이유도 한 줄씩 적어줘.

[할 일 목록 붙여 넣기]
```

머릿속이 복잡한 월요일 아침에 특히 쓸모가 있는 요청입니다.
다만 최종 순서는 팀 사정을 아는 내가 정해야겠죠.

### 예시 10. 발표 예상 질문 준비

```
아래는 내일 팀장 보고에 쓸 발표 내용이야.
듣는 사람이 던질 만한 날카로운 질문 5개를 뽑고,
각 질문에 30초 안에 말할 수 있는 답변 초안을 써줘.

[발표 내용 붙여 넣기]
```

혼자서는 놓치기 쉬운 반대 의견을 미리 짚어 볼 수 있습니다.
답변 초안은 내 말투로 다듬어서 연습해 보세요.

## 4. 챗GPT를 업무에 쓸 때 주의할 점은?

예시를 손에 익혔다면 이제 결과를 다듬고 점검하는 법을 알아볼 차례입니다.
첫 답이 마음에 들지 않는다고 대화를 새로 시작할 필요는 없습니다.

1. 첫 초안을 받습니다.
2. 빠진 점이나 아쉬운 점을 짚어 다시 요청합니다.
3. 분량과 형식을 맞춰 마무리합니다.

[IMAGE: 다이어그램 | 설명: 챗GPT 업무용 프롬프트 결과를 다듬는 3단계: 초안, 보완 요청, 형식 맞추기]

OpenAI 도움말도 결과를 보고 표현과 맥락을 조금씩 바꿔 가며
다시 묻는 방식을 권합니다.
같은 대화 안에서 이어 물으면 앞의 맥락을 그대로 쓰니 훨씬 편하죠.

다만 맡겨도 되는 일과 직접 확인할 일은 나눠서 생각해야 합니다.

| 잘 맞는 일 👍 | 직접 확인할 일 👎 |
| :--- | :--- |
| 메일·문서 초안 | 숫자, 날짜, 고유명사 |
| 긴 글 요약 | 회사 규정과 법 조항 |
| 아이디어 목록 | 최종 결정과 책임 |
| 수식과 목차 제안 | 고객·기밀 정보 입력 |

그럴듯한 통계나 출처를 붙여 왔는데
원자료와 맞춰 보니 다른 경우가 있다는 이야기가 많더라고요.
저도 숫자가 들어간 답은 원래 자료와 한 번 더 대조하는 습관을 들였습니다.

[IMAGE: 포인트카드 | 설명: 챗GPT를 업무에 쓸 때 주의할 점 3가지: 기밀 빼기, 숫자 확인, 최종 판단]

보안도 꼭 챙겨야 합니다.
2023년에는 국내 한 대기업에서 직원이 소스코드와 회의 내용을
챗GPT에 입력한 일이 알려지면서 사내 규정이 강화되기도 했죠.

저도 회의록을 정리하려다 고객 이름이 그대로 들어 있는 걸 보고
붙여 넣기 직전에 멈춘 적이 있어요.
고객 정보와 기밀 자료는 지우거나 가명으로 바꾸고,
회사의 AI 사용 규정부터 확인하시길 권합니다.
