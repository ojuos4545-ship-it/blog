# 클로드 코드 데스크톱 앱 사용법 3단계

> 💡 **한 줄 요약:** 클로드 코드 데스크톱 앱 사용법은 Code 탭 열기,
> 폴더 골라 일 맡기기, 바뀐 내용 검토하기의 3단계로 끝납니다.

[IMAGE: 썸네일 | 설명: 클로드 코드 데스크톱 앱 사용법 3단계 대표 이미지]

"터미널은 낯선데 클로드 코드는 꼭 써 보고 싶어요"
하시는 분들을 위해 준비했습니다.
결론부터 말씀드리면, **클로드 코드 데스크톱 앱 사용법**은
Claude 앱을 설치해 Code 탭을 열고, 작업 폴더를 골라 할 일을 적은 뒤,
바뀐 내용을 검토하는 것까지가 전부입니다.

데스크톱 앱 안에 클로드 코드가 들어 있어서
Node.js나 CLI를 따로 설치하지 않아도 됩니다.
다만 앱만 깔면 바로 되는 줄 알았다가 Code 탭에서
업그레이드 안내를 보고 당황했다는 분이 꽤 많더라고요.

오늘 이 글 하나만 끝까지 읽으시면 터미널 없이
첫 작업을 맡기고 결과를 검토하는 데까지 혼자 하실 수 있습니다.
메뉴 이름과 요금제 조건은 [Claude Code 공식 문서](https://code.claude.com/docs/en/desktop-quickstart)를
2026년 10월 30일에 확인해 정리했습니다.

---

## 🛠️ 시작하기 전에 준비할 것들

* **준비물:** 유료 Claude 요금제(Pro, Max, Team, Enterprise)
* **컴퓨터:** macOS 또는 Windows (리눅스는 베타)
* **난이도:** 초급, 작업할 프로젝트 폴더 하나면 충분합니다

처음에는 내용을 잘 아는 작은 프로젝트로 시작해 보세요.
공식 문서도 이 방법이 가장 빨리 감을 잡는 길이라고 권합니다.
맥은 인텔과 애플 실리콘을 함께 지원하는 설치 파일 하나로 되고,
윈도우는 x64용과 ARM64용 설치 파일이 따로 있습니다.

전체 흐름을 먼저 알아 두면 덜 헷갈립니다.
설치하고 Code 탭을 연 다음, 폴더와 모델을 고르고,
할 일을 적은 뒤 바뀐 내용을 검토하는 순서죠.

[IMAGE: 다이어그램 | 설명: 클로드 코드 데스크톱 앱에서 설치부터 작업 맡기기, 변경 검토까지 이어지는 3단계 흐름]

---

## Step 1. 클로드 코드 데스크톱 앱은 어떻게 설치할까?

설치 자체는 어렵지 않습니다.
공식 다운로드 페이지에서 내 운영체제에 맞는 파일을 받아 실행하면 되죠.
아래 순서대로 차근차근 따라와 주세요.

1. 설치 파일을 내려받아 실행합니다.
2. 맥은 응용 프로그램 폴더, 윈도우는 시작 메뉴에서 Claude를 엽니다.
3. Anthropic 계정으로 로그인합니다.
4. 사이드바 맨 위의 **Code** 탭을 누릅니다.

(이때 주의할 점은 탭이 아이콘으로만 보일 수 있다는 것입니다.
아이콘 위에 마우스를 올리면 이름이 나오니
그중 Code를 찾으면 됩니다.)

[IMAGE: 포인트카드 | 설명: 클로드 코드 데스크톱 앱 설치 후 로그인하고 Code 탭을 여는 순서]

### Code 탭이 안 열릴 때는 어떻게 할까?

Code 탭을 눌렀을 때 뜨는 안내에 따라 해결 방법이 다릅니다.

* **업그레이드 안내:** 유료 요금제에 먼저 가입해야 합니다
* **온라인 로그인 안내:** 로그인을 마친 뒤 앱을 다시 시작합니다
* **403 오류:** 공식 문서의 인증 문제 해결 항목을 확인합니다

채팅은 잘 되는데 Code 탭만 열리지 않는다는 경우도 종종 보이더라고요.
이럴 때는 요금제가 활성 상태인지,
같은 계정으로 로그인했는지부터 확인해 보세요.

---

## Step 2. 폴더를 고르고 일은 어떻게 맡길까?

Code 탭이 열렸다면 이제 작업할 폴더를 정할 차례입니다.
입력창 아래 줄에 있는 버튼들로 환경, 폴더, 모델을 차례로 고르면 됩니다.

1. 첫 번째 버튼(환경)에서 **Local**의 맨 위 항목을 고릅니다.
2. 옆의 폴더 버튼에서 **Open folder…**를 눌러 프로젝트 폴더를 고릅니다.
3. 오른쪽 끝 모델 선택 메뉴에서 모델을 고릅니다.
4. 입력창에 할 일을 적고 **Enter**를 누릅니다.

입력창 아래에 환경 선택이 보이지 않는다면 이전 화면 구성이라
버튼 위치가 조금 다를 수 있습니다.
Local 대신 **Cloud**를 고르면 앱을 닫아도 작업이 이어지고,
**SSH**를 고르면 원격 서버에서 작업할 수 있습니다.

처음 할 일은 짧고 구체적으로 적어 보세요.
공식 문서의 예시처럼 이렇게 부탁하면 됩니다.

```
TODO 주석을 하나 찾아서 고쳐줘
```

[IMAGE: 포인트카드 | 설명: 클로드 코드 데스크톱 앱에서 환경과 폴더, 모델을 고르고 첫 작업을 맡기는 순서]

### 권한 모드는 무엇을 골라야 할까?

입력창 아래 줄에는 권한 모드 선택도 있습니다.
클로드가 내 승인 없이 어디까지 할 수 있는지 정하는 설정이라
처음 쓸 때 가장 많이 헷갈리는 부분이죠.

| 모드 | 동작 | 이럴 때 추천 |
| :--- | :--- | :--- |
| **Manual** | 파일 수정·명령 실행 전마다 승인을 물음 | 처음 써 볼 때 |
| **Accept edits** | 파일 수정은 자동, 그 밖의 명령은 물음 | 빠르게 고칠 때 |
| **Plan** | 파일을 고치지 않고 계획만 제안 | 큰 작업을 하기 전 |
| **Auto** | 위험한 동작만 막고 나머지는 진행 | 메뉴에 보일 때만 |

저도 처음엔 Accept edits로 바꿨는데도 명령을 실행할 때마다
승인 창이 떠서 설정이 안 먹힌 줄 알았어요.
알고 보니 이 모드는 파일 수정과 간단한 파일 명령만 자동으로 받고,
나머지 터미널 명령은 여전히 묻는 게 정상이더라고요.

[IMAGE: 비교표 | 설명: 클로드 코드 데스크톱 앱 권한 모드 Manual, Accept edits, Plan, Auto의 장점과 주의점 비교]

> 📌 **전문가 Tip:** 큰 작업은 Plan으로 계획부터 받아 보세요.
> 계획이 마음에 들면 Accept edits나 Manual로 바꿔 실행하면 됩니다.
> Plan은 지금 세션에만 적용되고, 다른 모드는 폴더별로 기억됩니다.

## Step 3. 바뀐 내용은 어떻게 검토할까?

기본이 끝났다면 이제 클로드가 고친 내용을 확인해 볼 차례입니다.
파일이 바뀌면 `+12 -1`처럼 더하고 뺀 줄 수가 표시되는데요.
이 숫자를 누르면 파일별로 바뀐 부분을 보여 주는 diff 화면이 열립니다.

1. 줄 수 표시나 제목 표시줄의 **Changes** 버튼을 누릅니다.
2. 고치고 싶은 줄에 마우스를 올리고 줄 번호 옆 **+**를 누릅니다.
3. 의견을 적고, 맥은 **Cmd+Enter**, 윈도우는 **Ctrl+Enter**로 보냅니다.

의견을 받으면 클로드가 다시 고치고 새 diff를 보여 줍니다.
클로드에게 직접 검토를 맡기고 싶다면
입력창에 `/code-review`를 입력해 보세요.

[IMAGE: 포인트카드 | 설명: 클로드 코드 데스크톱 앱 diff 화면에서 줄마다 의견을 달아 수정을 요청하는 순서]

### 작업 중에 방향을 바꾸고 싶다면?

작업이 끝날 때까지 기다릴 필요는 없습니다.
정지 버튼을 누르면 바로 멈추고, 고칠 내용을 적어 **Enter**를 누르면
진행 중인 작업을 멈추지 않고 방향만 바꿔 줄 수 있습니다.

* **`@파일이름`:** 특정 파일을 대화에 바로 불러옵니다
* **터미널:** 제목 표시줄의 **Terminal** 버튼으로 엽니다
* **사이드 채팅:** `/btw`로 본 작업과 따로 질문합니다
* **새 세션:** **+ New**로 여러 작업을 나란히 진행합니다

하지만 중요한 건 빨리 끝내는 것이 아니라
**커밋 전에 diff를 한 번 훑어보는 습관**이겠죠.
승인을 아예 묻지 않는 Bypass permissions 모드도 있지만,
공식 문서는 격리된 컨테이너나 가상 머신에서만 쓰라고 안내합니다.
