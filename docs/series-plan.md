# 클로드 코드 블로그 시리즈 계획

> 독자: 클로드 코드 입문자. 1~10번은 기능 익히기(입문편), 11~20번은 익힌 기능으로 실제 작업하기(실전활용편).
> 제목은 공백 포함 25자 이내, 메인 키워드는 제목 앞쪽에 1회 (SEO 가이드 4장).

## 1부. 입문편 (1~10, 발행 완료)

핵심 기능 5가지 총정리, CLAUDE.md 작성법, 훅(Hooks), 권한 모드, 스킬(Skills), 서브에이전트,
컨텍스트 관리, MCP, 슬래시 명령어, 플러그인

### 3부 메모

- 제목은 실제 검색어처럼 "클로드"로 시작해도 된다. 메인 키워드는 여전히 1회.
- 14번 제목은 검색어 "vs 코드 클로드 쓰는법"에 맞춰 "클로드 VS Code 쓰는 법 3단계"로 바꾸는 것을 검토한다.
- 27번(요금제)은 내용이 자주 바뀐다. 기준 날짜를 제목 아래에 적고, 발행 직전에 공식 페이지로 확인한다.
- 28번(비교)은 한쪽을 깎아내리지 않는다. 직접 써본 경험을 근거로 장단점 표로 정리한다.
- 30번은 1~29번 글로 가는 링크를 모은 허브 글로 만든다. 블로그 안 이동이 늘어 체류 시간에 도움이 된다.
