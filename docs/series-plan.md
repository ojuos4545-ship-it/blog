# 클로드 코드 블로그 시리즈 계획

> 독자: 클로드 코드 입문자. 1~10번은 기능 익히기(입문편), 11~20번은 익힌 기능으로 실제 작업하기(실전활용편).
> 제목은 공백 포함 25자 이내, 메인 키워드는 제목 앞쪽에 1회 (SEO 가이드 4장).

## 1부. 입문편 (1~10, 발행 완료)

핵심 기능 5가지 총정리, CLAUDE.md 작성법, 훅(Hooks), 권한 모드, 스킬(Skills), 서브에이전트,
컨텍스트 관리, MCP, 슬래시 명령어, 플러그인

## 2부. 실전활용편 (11~20)

### A. 작업 환경 다지기 (11~15)

| 순서 | 제목 | 다루는 내용 | 앞 글과의 연결 |
| :--- | :--- | :--- | :--- |
| 11 | 클로드 코드 요청 잘 쓰는 법 3단계 | 목표·조건·확인 방법 담기, 이미지 첨부 | 기능을 갖췄으니 "어떻게 시킬까"로 2부를 연다 |
| 12 | 클로드 코드 되돌리기 사용법 3단계 | 체크포인트로 이전 상태 복구 | 요청이 빗나갔을 때 바로 쓰는 안전장치 |
| 13 | 클로드 코드 깃 커밋·PR 맡기기 | 커밋 메시지, PR 생성 | 되돌리기는 대화 안에서만, 오래 남기려면 Git |
| 14 | 클로드 코드 VS Code 사용법 3단계 | 에디터 연동, 바뀐 부분 화면으로 확인 | 터미널이 낯선 독자를 위한 편한 환경 |
| 15 | 클로드 코드 웹·모바일 사용법 | 브라우저·휴대폰에서 작업 맡기기 | GitHub 저장소가 필요해 13번 다음 |

## 메모

- 12번이 4번(권한 모드)과 겹치면 "GitHub Actions 연동"으로 바꾼다.
- 13번은 Git 기초 설명을 줄이고 "클로드에게 맡기는 법"에 집중한다.
- 20번은 에세이형(C). 필자의 실제 경험이 근거라 경험 문장을 쓰기 가장 쉽다.
- 명령어·화면은 글을 쓰기 직전에 공식 문서로 다시 확인한다.
