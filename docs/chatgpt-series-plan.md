# 챗GPT 입문자 시리즈 계획 (1~10)

> 근거: 클로드 시리즈 조회수 순위 3회분(2026.10.30~11.01 확인).
> 잘 나온 글의 공통점 6가지를 챗GPT 주제에 그대로 옮겼다.
> 제목은 공백 포함 25자 이내, 메인 키워드 "챗GPT"는 제목 맨 앞에 1회 (SEO 가이드 4장).

## 클로드 시리즈에서 확인한 패턴

| 패턴 | 클로드 글 예시 (조회수) |
| :--- | :--- |
| 돈 | 요금제·사용량 총정리 (23, 18) |
| 비교 | 커서 차이 5가지 비교 (13) |
| 뜻 | 에이전트 뜻 (18), 용어 뜻 15가지 (12~13) |
| 예시 모음 | 디자인 프롬프트 예시 5가지 (11~14) |
| 연결 | 노션 MCP (7~15), 깃허브 MCP (10) |
| 쓰는 환경 | VS Code (11~23), 웹·모바일 (6~16) |

하위권: 에러 해결, 깃 커밋·PR, 되돌리기, "잘 쓰는 법"처럼 막연한 방법론 글.

## 발행 순서

| 순서 | 제목 | 패턴 | 메모 |
| :--- | :--- | :--- | :--- |
| 1 | 챗GPT 핵심 기능 5가지 총정리 | 총정리 | 카테고리 입구 글. 2~10번 링크를 모은다 |
| 2 | 챗GPT 요금제 총정리, 무료와 유료 차이 | 돈 | 기준 날짜 명시, 발행 직전 공식 페이지 확인 |
| 3 | 챗GPT 클로드 차이 5가지 비교 | 비교 | 기존 클로드 글로 내부 링크. 직접 써본 경험 근거 |
| 4 | 챗GPT 에이전트 뜻과 사용법 | 뜻 | 클로드 "에이전트 뜻" 2위 공식 재현 |
| 5 | 챗GPT 용어 뜻 15가지 총정리 | 뜻 | GPTs, 토큰, 프롬프트, 메모리 등 |
| 6 | 챗GPT 업무용 프롬프트 예시 10가지 | 예시 모음 | "잘 쓰는 법"이 아니라 "예시"로 |
| 7 | 챗GPT 이미지 만들기 3단계 | 예시 모음 | 프롬프트 예시 포함 |
| 8 | 챗GPT 구글 드라이브 연결 방법 3단계 | 연결 | 메뉴 이름은 발행 직전 확인 |
| 9 | 챗GPT GPTs 뜻과 만드는 법 3단계 | 뜻 + 방법 | 나만의 챗봇 만들기 |
| 10 | 챗GPT PC·모바일 앱 사용법 3단계 | 쓰는 환경 | 설치부터 첫 대화까지 |

## 메모

- 챗GPT는 기능과 요금이 자주 바뀐다. 모든 글은 쓰기 직전에 공식 문서·화면으로 확인하고 기준 날짜를 적는다.
- 검색어는 "챗GPT"와 "챗지피티"가 섞여 쓰인다. 제목은 "챗GPT"로 하고, 본문과 태그에 "챗지피티"를 1회씩 넣는다.
- 블로그 주제가 클로드에서 넓어지므로 별도 카테고리("챗GPT 입문")를 만든다 (SEO 가이드 9장 주제 일관성).
- 새 글은 발행 1~2일에 조회수가 몰리고 줄어든다. 하루 1편씩 꾸준히 발행한다.
